## 一、实验变量（一次只动一个）

- 新增行为：**宽度由 ≥attack 跌入 <attack 当日立即走正常调仓流程**
  （in_mid_zone 路径收敛到 mid_cap 上限；mid_cap=0 时 plan={} → diff 全清）。
- 不变量：调仓时钟 `_last_rebalance_bar` 仅在常规节拍日更新——降档出清
  不重置时钟，防挤占/推迟后续正常调仓。
- 对照基准：宽度冠军 `bd25a35m00i1`（实测值见 PLAYBOOK 台账，此处不抄数），
  同 universe 截面（缓存 2595 只，对比前核 universe_hash）。

## 二、针对的瓶颈（归因链，非直觉）

2020 失血归因：-10.8% = ice 档 -14.7%/41d + **mid 档 -4.7%（34 天 @31%
仓位，跌入警戒区后非调仓日不出清——结构性漏洞）** + attack +8.8%。
mid_cap=0 此前只在调仓日生效，本实验把它扩展为「跨界当日生效」。
预期改变：mid 档持仓天数 → ~0，2020 类区间的 -4.7% 贡献应大部分消除。

## 三、实现审计要点（代码已核对 candidates.py ③.5/④/⑥）

| 检查项 | 代码位置 | 预期 |
|---|---|---|
| 跨界判定 | `demote_due`：`prev_b ≥ attack` 且 `今日 b < attack` 且非 ice | 只在 attack→mid 跨界日触发一次；mid 持续期不重复触发 |
| 出清路径 | 走正常调仓流程（非旁路清仓单），in_mid_zone + mid_cap=0 → plan={} → diff_to_orders 全卖 | 与普通调仓同口径的手续费/T+1 语义 |
| 时钟隔离 | `if scheduled: _last_rebalance_bar = bar_count` | demote 日不更新时钟，下一节拍不推迟 |
| ice 优先级 | ③.5 冰点分支在前，`return` 短路 | 冰点确认/已冰逻辑不受 demote 影响 |
| fail-closed | 宽度缺失 raise | 无静默降级 |

## 四、行为探针（出指标前必须先跑，E4 先例）

回放断言（参照 `experiments/lab/e4-risk-audit/probe_replay.py` 模式）：
1. 找 3 个 attack→mid 跨界日：断言当日产生卖单且净卖出后仓位 ≤ mid_cap；
2. 断言跨界日的 `_last_rebalance_bar` 不变（下一调仓日 = 原节拍）；
3. 断言 mid 持续期非调仓日不再产生订单（防每日重复出清空转）；
4. 断言 ice_pending→ice 确认路径不受影响（原有测试已覆盖，全绿前提）。
