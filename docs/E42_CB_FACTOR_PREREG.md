# E42 可转债因子族影子筛选预登记（冻结版）

> 冻结时间：2026-09-21（先于任何筛选运行）。
> 数据：`data/cb/`（子会话全史落地：1111 券、日线 82 万行
> 2000→2026-09-21、转股溢价 1088 券；摘牌券 736 只有摘牌日——
> 幸存者偏差防线在位）。memo 34 首推轴。

## 一、假设与先验

可转债 T+0、无印花税、有债底——散户可交易性高于股票。
外部证据（memo 34 调研）：双低因子（低价+低溢价）2022 年前
RankIC 稳定为正、**2022 后转负**——故本族自带年代分段判定，
不以全期均值掩盖衰减。

## 二、臂阵（4 假设 + 合成披露臂，Bonferroni α 按 4 计）

| 臂 | 构造 | 方向 |
|---|---|---|
| C1 | 双低 = rank(收盘价)+rank(转股溢价率) | 低好 |
| C2 | 转股溢价率 | 低好 |
| C3 | 纯债溢价率（债底贴近度） | 低好 |
| C4 | 转债 20 交易日动量 | 高好 |
| CX | ≥2 弱及以上 → z 等权合成（披露臂不入基数） | — |

月末截面信号 → 次月持有收益（债券自身月收益）。
宇宙 = 当月已上市且未摘牌转债（listing_date≤T<delist_date），
上市 <10 交易日剔除（上市初期定价噪声）。
基线 = 转债宇宙等权月收益（含已摘牌券的全期样本）。
成本 = 0.1%/单边（转债零印花、佣金万分级，取保守）。

## 三、判定门

- 判「强」：net top-quintile spread（多头端−宇宙等权）或 RankIC
  月序列 |t|≥2.6 且方向符合先验，且年代一致性≥60%（按年同向）。
- **E 时代分段门（本族特有）**：2022-01 起子窗 IC/spread 均值须
  与全期同号——全期强而 2022+ 翻负 → 判「衰减」如实登记，
  不晋级（memo 34 预告的双低衰减专门门）。
- 判「负」：|t|<2.6 或方向反。
- INCONCLUSIVE：有效月 <48 或月均宇宙 <30 券。
- 2025+ 同样分段报告但只做观察登记（永久 OOS 纪律）。
- 溢价率字段缺测日该券缺席当月截面（如实，不填充）。

## 四、范围与红线

- 判「强」≠进引擎——转债引擎（T+0/无涨跌停/手单位/强赎条款）
  是独立工程，判定落地前先经范畴评估（净边际、篮宽、容量）。
- 不补造缺失券；源端缺口（57 上古券 meta 回落 cninfo 等）
  沿子会话 manifest 如实登记。
- 事件驱动类转债玩法（下修/强赎博弈）不在本族——
  需公告轴，另行预登记。

## 五、已知局限

- 转债 2017 年前样本稀薄（<100 只），早期月份功效低；
  G 门按月覆盖率如实判。
- 强赎/下修事件会在个券收益里留下跳变——影子筛选如实承担，
  引擎化时才需事件剔除层。
