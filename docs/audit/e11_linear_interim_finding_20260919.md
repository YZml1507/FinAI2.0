# e11-linear 主实验中间发现（2026-09-19）：预登记对照缺陷与暴露归因

> 状态：**中间结论**（主实验已出，15 格扰动矩阵在跑：6/16）
> 裁决依据：`docs/E11_LINEAR_PREREG.md` §七（判据预先固定，⛔ 不许事后放宽）

## 一、主实验结果（硬事实）

| 指标 | e8b（hard, mid_cap=0） | e11-linear | 差 |
|---|---|---|---|
| CAGR | 8.58% | **6.32%** | **-2.26pp** |
| MDD | 17.40% | **24.40%** | **+7.00pp** |
| 年化换手 | 4.61 | 6.45 | +1.84 |
| round_trips | 156 | **312** | +156（翻倍） |
| 手续费 | 22,328 | 26,763 | +4,435 |
| 胜率 | 44.23% | 41.03% | -3.2pp |

**按预登记 §七 判据：CAGR 退化 2.26pp > 1.5pp ⇒ 「代价过大」**
（该判据已预先固定，本节照旧执行，不放宽）。

## 二、归因：不是「阶跃→斜坡」的代价，是「暴露增加」

用户口径验证（真实宽度序列 2846 日，未跑回测纯计算）：

| 量 | 值 |
|---|---|
| mid 带 [0.25,0.35) 天数 | 388（13.6%），b 均值 0.2996 |
| linear 在 mid 带 cap 均值 | **0.496**（(b-0.25)/0.10 的日度均值） |
| hard 在 mid 带 cap | **0**（mid_cap=0 语义） |
| 全序列日度平均目标仓 | linear **70.74%** vs hard **63.98%** |
| **平均暴露增量** | **+6.76pp** |

### 结论：e11-linear 不是「纯接口改造」，而是「同时加了 6.8pp 平均仓位」

- hard + mid_cap=0：mid 带 **零仓**；
- linear + mid_cap=0：mid 带 **0→100% 线性**（均值 49.6%）。

而 mid 带是**已实证的负 alpha 区间**（PLAYBOOK：「mid 档 -4.7% @31% 仓位」；
C2 报告亦同向）。⇒ 在负 alpha 区间加仓，**收益与回撤同时恶化**，
与既有 `mid_cap=0`（警戒区零仓）裁决**完全一致**，是同一结论的再次确认。

## 三、⭐ 预登记缺陷（本窗口实锤，须登记）

预登记 §一 写「唯一变量 breadth_weight_mode」在**名义上**成立，但在
**语义上**混淆了两个因素：

1. 仓位形态（阶跃 vs 斜坡）；
2. 仓位水平（mid 带 0% vs 49.6%）。

⇒ 当 mid_cap=0 时，`linear` 与 `hard` **不是暴露等价对照**，无法隔离因素 1。
本窗口的 e11 主实验因而**不能**回答「连续映射本身是否好」，只能回答
「在 mid_cap=0 构型上切到 linear 会怎样」（答案：变差，原因见 §二）。

**这不推翻 e11 的 G-2 价值**：15 格扰动矩阵内部各格**同为 linear**，
暴露水平相近，G-2a/b/c 平台宽度判据在该集合内**仍然可比、仍然有效**。

## 四、正确的暴露等价对照（e13 提案，须独立预登记）

| 臂 | mid 带 cap | 全序列平均目标仓 | 用途 |
|---|---|---|---|
| e8b（已有） | 0（恒定） | 63.98% | 暴露低 + 平台 |
| **e11-linear（已有）** | 0→100% 线性 | **70.74%** | 暴露高 + 斜坡 |
| **e13a（新）** | **50% 恒定** | **70.78%** | **暴露高 + 平台（对照臂）** |

暴露差仅 0.04pp ⇒ e13a vs e11-linear **干净隔离「斜坡 vs 平台」**：

- 若 e13a ≈ 6.3% ⇒ 损失全来自暴露，**斜坡形态本身无害**（G-2 可修）；
- 若 e13a ≈ 8.6% ⇒ **斜坡形态本身有害**（连续映射路线判负）；
- 若 e13a 居中 ⇒ 两因素各有贡献，按比例分解。

同时 e13a vs e8b 隔离纯「暴露增加」效应（形态相同=都是硬切）。

## 四·补：R11 精确化归因（同日后续分析）

本文 §二 的「平均暴露 +6.76pp」被 R11（`docs/audit/r11_breadth_threshold_validity_20260919.md`）
**精确化为**：收益对宽度的关系是 **W 形**（30-35% 为 dead zone，−0.54%~−0.69%，10 年中
7 年为负），而 linear 的权重函数在 [0.25,0.35) **单调递增**（0→1.0）⇒
**恰把仓位重心压在该坏带上**（b=0.30-0.35 给 50%-100% 仓）。hard+mid_cap=0
在整个带内给 0 仓，天然规避。⇒ 失败机制是「权重单调性方向与收益结构冲突」，
不只是「暴露水平上升」。

## 五、诚实边界

1. 本节 §二 的暴露口径是**日度目标仓**（未计调仓节拍的路径依赖、
   T+1 结算、现金计息），与回测实测暴露非严格相等；
2. round_trips 翻倍（156→312）是 linear 的**路径效应**（每次调仓日 cap
   不同 ⇒ 目标市值漂移 ⇒ 频繁小幅调仓），预登记 §五 影子前瞻已预判换手
   上升（实测 6.45 落在预测区间 4.6~8 内），方向一致；
3. 本节不改变 e11 主实验的**预登记裁决结论**（代价过大），只解释其归因。
