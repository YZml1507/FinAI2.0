# e14-bump 影子前瞻判负：非单调权重（凸包带）增量为负（2026-09-19）

> 复跑：`scripts/lab/e14_bump_shadow.py`
> 产物：`experiments/lab/e14-bump/_shadow/shadow_e14_bump.{json,md}`
> **地位**：只读影子分析（预登记前预检）。⛔ 非回测、非基线、非裁决——
> 影子层证据用于决定「是否值得立项预登记」，本案结论：**不值得**。

## 一、设计与动机

R11 分桶实证：宽度→前瞻收益呈 W 形——25-30% 桶前瞻5日 +0.61%（166 天）、
30-35% dead zone −0.69%（168 天）。hard+mid_cap=0 把 [0.25,0.35) 全置零 ⇒
好带 25-30% 被连带规避。bump 形态 = `[defense,dz_edge)` 给 bump_cap=0.5、
`[dz_edge,attack)` 仍 0（dz_edge=0.30 先验固定，唯一新自由度）。

影子口径 = **增量袖子**（bump_arm − hard_arm）：hard 在 <attack 恒 0 ⇒
增量袖子只在 b∈[0.25,0.30) 非零。严格复刻 candidates.py 事件序列：
20 日调仓节拍（demote/ice 不重置时钟）、demote=0.35 下界穿越当日至
bump cap、ice=1 日确认次日清仓、mid 带内 0.30 跨界不触发事件（持仓惯性）、
T+1 开盘成交分两段记账、费 买0.04%/卖0.09%、exdiv 现金+送转股数、
现金机会成本 GC001 日息。

## 二、结果：全象限为负

| 指标 | 实测 |
|---|---|
| bump 带天数 | 167 天（b∈[0.25,0.30)）；袖子持仓 202 天（含死区惯性） |
| 建仓/清仓事件 | 50 次；费用拖累合计 2.16% NAV |
| **增量总收益** | **−7.56% ⇒ 年化 ΔCAGR ≈ −0.78pp** |
| 袖子自身 MDD | 11.83%（增量回撤代价上限 proxy） |

分年增量：2015 +0.32 / 2016 +0.76 / 2017 0.00 / 2018 +0.41 / 2019 +0.68 /
**2020 −0.73 / 2021 −2.82 / 2022 −2.11 / 2023 −0.83 / 2024 −3.42**
（近 5 年连续为负且逐年加深——非随机噪声形态）。

归因（episode 按建仓事件×入带方向分解，累计增量）：

| 事件类型 | 方向 | 累计增量 |
|---|---|---|
| rebalance | falling | −4.98% |
| rebalance | rising | −1.76% |
| demote | falling | −0.50% |
| demote | rising | −0.19% |

**四象限全负**：上升沿建仓也亏 ⇒ 不存在「只做上升沿」的可挽救变体
（事后切分子形态即曲线拟合，不再追加）。

## 三、结论与对研究路线的意义

1. **R11 的 EW 桶证据不传递到策略持仓**：等权 487 池 25-30% 桶
   +0.61%/5d，而策略实际选出的 top-5 高股息市值加权篮子在同一带内亏钱——
   R11 §6 的诚实边界（EW proxy ≠ 策略持仓）坐实。高股息排序在弱宽度 regime
   选中的是价值陷阱，不是低估反弹。
2. **mid 带加仓第四次独立判负**（机制各不相同）：
   - e11-linear 单调斜坡：−2.26pp（全 G-2 FAIL）
   - e13a 暴露等价分解：暴露效应 −1.45pp（恒等式闭合）
   - e14-bump 非单调凸包：−0.78pp（影子层，四象限全负）
   - 加上 e8b 本身就是 mid_cap 0.5→0 的产物
   ⇒ **元结论：该策略的 alpha 只存在于 attack 档（b≥0.35）；mid 带
   任何形式的加仓都是净亏**。「阈值稳健性机制」方向在接口层正式收敛关闭：
   不是映射形状的问题，是 mid 带持仓本身负期望。
3. **流程收益**：影子预检挡下了一整轮（10 组×~10min）注定判负的实验——
   E11 以来「影子先行」的工作流首次在预登记前完成拦截。

## 四、诚实边界

- 影子不模拟 plan_positions 的 2 万单票下限/流动性/整手化——低 NAV 早年
  可能高估持仓数（偏乐观方向，不改变负号结论）；
- ΔNAV 一阶复乘近似，二阶交互忽略；
- 增量 MDD 用袖子自身净值口径（上限 proxy），非全组合回撤；
- 本报告不构成对 e11/e13a 既有裁决的任何修订。
