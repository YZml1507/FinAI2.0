## 1. 交付物定位与决策摘要

### 1.1 现在是什么局面

**一句话：工程引擎是真的，但我们已经失去了"判断策略好坏的能力"。** 账本、撮合、费率、红利税、数据口径经得起查（审计 §8.1）；但**所有对外结论、全部门禁、Phase 4 准入、以及要交券商的合规包，都是无效的**——因为同一份 T312 回测在仓内存在三套互斥指标，门禁在真实调用路径下 23/24 空转，合规包载有编造数字与虚假方法论声明。

**当前状态不是"策略效果不理想"，而是"度量衡没校准"。** 在度量衡修好之前，任何 A/B 策略结论都无法采信。

### 1.2 下一步该做什么（决策摘要）

| 类别 | 内容 | 是否可选 |
|---|---|---|
| **止血（P0，不可选）** | 撤回/作废全部失实合规对外材料；停止一切"已准入/6 个月跟踪"对外表述；把编造数字标注为无出处 | ❌ 必做 |
| **治理重做（P0，不可选）** | 落地 8 条门禁需求（§4）+ 修正 SKIP 语义 + 定位复现性缺陷 | ❌ 必做 |
| **策略路线（需用户拍板）** | A（修仓位+降频，保留个股） / B（ETF 增强） | ✅ 可选，但**必须排在治理重做之后** |

### 1.3 关键问题的明确立场：「门禁重做之前，还存在"可以继续推进策略"的合法路径吗？」

**立场：不存在。**

理由不是风险偏好问题，而是逻辑问题：

1. **新结论同样无机器保护。** 门禁是唯一能拦住"编造数字、MDD 超限、0 成交假通过"的机制。门禁空转时，新跑出的任何回测结论与今天的 10.72% 幽灵数字**在治理意义上是同一类东西**——都只有人眼背书，没有机器背书。
2. **连"事实源"本身都不自洽。** 仓内 4 份产物的 `params_hash` 完全相同（`f54c298d5168eac5`），却给出 3 种互斥结果（见 §1.4）。这意味着**当前连"重跑一次能否复现"都未被证明**。在复现性未闭环前推进策略，等于在流沙上盖楼。
3. **合规风险会随时间放大。** 每多跑一次策略、每多写一份带数字的文档，都是一份新的"可能进入券商报备包"的失实材料。止血必须先于推进。

**唯一合法例外（不构成"推进策略"）**：在门禁重做的同时，允许以「**只重跑、只落盘、不写任何结论、不对外引用**」的方式生成 dry-run 基线，用于**喂给新门禁做回归测试**。该基线的唯一用途是验证门禁本身，**不得据此宣布通过、不得写入合规材料、不得解锁 Phase 4**。

## 2. 三个选项的对比（A / B / C）

### 选项 A：修仓位 + 降频（保留个股红利策略）

**依据**：诊断证据可用（`docs/diagnosis/t312_full_period_diagnosis.md` 仓位类指标与产物一致）。核心诊断是「不是满仓选错票，是长期几乎没满仓」——日均持仓仅 0.5–1.8 只（契约目标 5）、零持仓日 54.7%、平均现金占比 65.4%。

**具体要改什么（必须先做归因，不要直接改参数）**：

| 参数（出处：`20260907-150402-*.json` `params`） | 当前值 | 怀疑问题 | 动作 |
|---|---|---|---|
| `portfolio.min_daily_amount` | 5000 万（当日成交额） | 是否过严导致候选枯竭 | **归因实验**：单参数放宽，看在持仓数上的边际效应 |
| `portfolio.min_position_value` | 2 万 | 叠加 100 股整手 + `max_price=300` 后挤出小仓位 | 归因实验 |
| `use_ma200_timing` | true | MA200 空仓贡献了多少零持仓日 | **拆解**「MA200 空仓天数 vs 过滤器空仓天数」（诊断 §4 P0 已要求） |
| `rebalance_days` | 20 | 换手 201.14% + 红利税 51.8% | 20 → 60/120，拉长持股降税档 |
| `candidate_pool_size` | 50 | 候选是否够建 5 只 | 归因实验 |
| `min_dividend_yield` | 0.03 | 阈值是否卡死建仓 | 归因实验 |
| `warmup_bars` | 210 | 冷启动期过长（T313 空仓的直接原因） | 评估可压缩空间 |

> ⚠️ 注意：审计**未证实**上述任一参数是"建不满仓"的主因。诊断只给了现象（持仓不足），没给归因。所以 A 的第一步是**参数敏感性归因实验**，不是拍脑袋改值。**"改哪个、改到多少、能改善多少"一律需重跑后确定**——不得引用现有 md 的任何"预期收益"。

- **投入**：数据齐备（`data/dividend_stocks/` 487 标的 × 10 年），无需采集；成本 = 归因实验 + 多轮重跑。
- **预期改善（方向性，非数值）**：持仓数上升、现金占比下降、换手与红利税下降。**具体幅度需重跑后确定。**
- **风险**：
  1. **放宽流动性门槛 = 引入真实风险**。5000 万成交额阈值对"散户 2 万一笔"是**有物理意义的**（防冲击成本），不能为了建满仓无限放宽；
  2. **降频 → MA200 择时滞后更大**，牛市跑输可能加剧（诊断已显示 2019/2020/2024 大幅跑输）；
  3. **放宽股息率门槛 → 高息陷阱**（诊断 P2 已提示需质量过滤）。
- **成功判据**（对齐计划仓 G4.5，`tasks.md:58`：MDD<35% / 换手<400% / 胜率≥35%）：修满仓后①日均持仓趋近契约目标 5、零持仓日显著下降；②MDD<35%、换手<400%、胜率≥35%；③对 512890 超额转正。三条全中才算成功。
- **失败止损线**：修满仓后 2019–2024 仍明显跑输 512890 → **切 B**。

### 选项 B：ETF 增强（512890 红利低波 + MA200 择时）

**依据**：`data/etf_bars/` 数据齐备（`sh.512890`：1443 行，2019-01-18 ~ 2024-12-31，`adjust_mode=RAW + factor 列`，`null_rate=0.0`，见 `data/etf_bars/meta.json`），可立即回测。

- **优势**：
  1. **无个股踩雷**（无财务造假、无退市、无停牌深套）；
  2. **无 FIFO 红利税扣缴环节**——消除当前第一大摩擦（红利税 5043.75 元，占总费用 51.8%，出处 `20260907-150402-*.json`）。⚠️ ETF 分红环节的个税口径**须与券商确认**，本文不预判；
  3. **无 5 元佣金地板磨损**——组合只 1–2 个标的，单笔金额大，天然避开"2 万一笔触发 5 元地板"的刚性摩擦；
  4. 费率低、执行简单、维护成本低。
- **劣势**：
  1. **超额空间窄**：收益来源退化为 β + 择时，几乎没有 α；
  2. **强依赖 MA200 择时准确度**——而择时在震荡市的磨损恰恰是当前策略已暴露的问题；
  3. **与"选股能力"假设脱钩**：放弃了个股红利策略的全部研究投入；
  4. **⚠️ 数据窗口硬约束**：512890 仅 2019–2024（6 年），**无法覆盖 2015 股灾与 2018 熊市压力区间**，长周期与极端市况验证严重受限。
- **需要什么验证**：512890+MA200 增强回测（2019–2024）对比 buy&hold 512890 与 510300；产出 3 项：年化/CAGR、MDD、换手。全部落 `experiments/runs/*.json`（带签名）。
- **成功判据**：增强后 CAGR > buy&hold 512890，且 MDD 显著低于 buy&hold，且换手极低；跑赢 510300。
- **失败止损线**：择时增强跑不过 buy&hold → 退化为"纯持有 512890"，或回到 A。

### 选项 C：先停止策略优化，把治理层修好再回来

**这不是 A/B 的替代项，而是 A/B 的前置条件。** 之所以单列，是因为它常被当成"浪费时间"而跳过——恰恰相反，它是**唯一能让 A/B 结论成立的路径**。

- **为什么必须先行**：
  1. **度量衡没校准**——在污染的地基上做 A 或 B，新结论同样会被污染，且很可能再次流进券商报备包（法律风险二次放大）；
  2. **权威仓已被污染**——错误数字（换手 92.51%/胜率 46.88%）已镜像进计划仓 `tasks.md:57,125`（审计 N7）。计划仓是"做什么、验收标准"的权威，它脏了，A/B 的验收判据本身就不可信；
  3. **门禁是虚假安全感**——"24 道机读防伪门禁"实测 23 SKIP / 1 PASS（审计 §6.1），比没有门禁更危险；
  4. **复现性未闭环**（PM-1）——连"重跑能否复现"都未证明。
- **投入**：8 条门禁需求落地（§4）+ 全仓文档口径重算 + 合规包重写 + 复现性定位。
- **验收判据**：新门禁在**真实回测路径**下能拦下①43.08% MDD、②幽灵数字 10.72%、③引用不存在路径；且全仓测试全绿、`test_t405_compliance_and_paper_e2e.py` 改正后仍绿。
- **止损线**：不适用——**C 是必做项**。跳过 C 直接做 A/B，即§1.3 所述"无合法路径"。

**三选项小结**：C 是前置（不可选）；A 与 B 是 C 之后的可选策略路线。A 保留选股假设且数据覆盖 10 年（含压力区间）；B 更简洁但只能验证 6 年、且放弃 α。

## 3. 我的推荐路线与理由（明确，不含糊）

### 推荐：**先 C（治理层重做，含止血）→ 再 A（以"归因实验"起步）→ A 失败则切 B。**

**理由（按优先级）**：

1. **C 必须最前**——因为它不是"路线选择"，是"让路线选择有意义"的前提（§1.3、§2-C）。把 C 排在后面，等于让后面所有决策都建立在不可信的数字上。
2. **A 优先于 B**——三个理由：①**数据覆盖**：A 可用 10 年数据（含 2015/2018 压力区间），B 只有 6 年；②**保留假设**：A 不放弃"红利选股"这一已投入大量研究的能力假设，若 A 修满仓后成功，价值远高于 B；③**诊断支持**：核心病因是"建不满仓"而非"选错票"，A 直接对症下药。
3. **A 必须以"归因实验"起步**——不要直接改参数值。先跑参数敏感性，回答"到底是 MA200、还是流动性门槛、还是股息率阈值把仓位卡死的"。**没有归因就改参数 = 用新的猜测替换旧的猜测。**
4. **B 作为 A 的兜底与对照**——B 的验证可**与 A 并行**（都需要先修好 MDD/一致性门禁），作为 A 的 benchmark。

### 第一个 48 小时内该做的 3 件事

1. **止血 / 合规（法律优先）**：给 `docs/compliance/` 全部材料 + `docs/t313_dividend_stress_report.md` + `T312_FINAL_SUMMARY.md` + `docs/delivery/PHASE4_ADMISSION_RESOLUTION.md` + 计划仓 `tasks.md` 的错误数字，统一打上「作废 / 无出处 / 待重写」批注（保留留痕，不删除）；撤回报备附件；停止一切"已准入 / 6 个月跟踪中"对外表述（详见 §5）。
2. **门禁 P0 四件套落地并对真实回测跑通**：MDD 上限门禁、文档↔产物一致性门禁、压测有效性门禁、引用路径存在性门禁；同时把 `SKIP` 移出 `is_pass`。判据：对权威产物 `20260907-150402` 运行 → MDD 门禁判 **FAIL**，一致性门禁对 92.51% 判 **FAIL**，空 context 下不再打印"全绿"。
3. **定位复现性缺陷（PM-1）**：查清"同一 `params_hash` 四份产物 3 种结果"的根因（数据快照 / 暖机窗口 / 未入哈希的输入）。这是所有后续结论的地基——地基不牢，A/B 都白做。
