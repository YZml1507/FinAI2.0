## 0. 一句话结论

**这个项目的工程引擎是真的，但"判断策略好坏的能力"已经失效了。**
账本、撮合、费率、红利税 FIFO、数据口径都经得起查；但**同一份 T312 十年回测在仓内存在三套互斥指标，其中两套在全部回测产物中都不存在**；被宣传为「24 道机读防伪门禁」的体系在真实调用路径下**只有 1 道在跑**；**要交给券商的合规报备材料载有 7 处失实数据与 2 处虚假方法论声明**；Phase 4「已准入 6 个月跟踪」实为 **1 天、0 成交、NAV 平直**的空跑。

所以现在的处境不是「策略效果不理想」，而是**度量衡没校准**。在度量衡修好之前，任何策略结论都无法采信。

## 4. 后续该怎么走（推荐路线）

### 明确立场

> **在门禁重做之前，不存在任何"可以继续推进策略"的合法路径。**
> 理由不是风险偏好，而是逻辑：门禁是唯一能拦住"编造数字 / MDD 超限 / 0 成交假通过"的机制。门禁空转时，新跑出的任何结论与今天的 10.72% 幽灵数字**在治理意义上是同一类东西**——只有人眼背书，没有机器背书。
>
> 唯一例外（不构成推进）：允许以「只重跑、只落盘、不写结论、不对外引用」的方式生成 dry-run 基线，**用途仅限于验证新门禁本身**。

### 推荐：**先 C（治理重做 + 止血）→ 再 A（以"归因实验"起步）→ A 失败则切 B**

**为什么 C 必须最前**：它不是路线选项，而是"让路线选择有意义"的前提。度量衡没校准，A/B 的结论会同样被污染，且很可能再次流进券商报备包（法律风险二次放大）。且错误数字**已镜像进权威仓**，A/B 的验收判据本身已不可信。

**为什么 A 优先于 B**：① A 有 10 年数据（含 2015 股灾 / 2018 熊市压力区间），B 的 512890 只有 6 年（2019–2024），**覆盖不了极端市况**；② A 保留"红利选股"的能力假设；③ 诊断指向的病因是"建不满仓"（日均持仓 0.5–1.8 只 / 目标 5，零持仓日 54.7%，平均现金 65.4%），A 直接对症。

**A 必须以"归因实验"起步，不要直接改参数**：先回答"到底是 MA200 空仓、还是流动性门槛 5000 万、还是股息率阈值 3% 把仓位卡死的"。**没有归因就改参数 = 用新的猜测替换旧的猜测。**

**B 作为兜底与对照**：可与 A 并行跑，作为 benchmark。

### 第一个 48 小时的 3 件事

1. **止血 / 合规（法律优先）**：给 `docs/compliance/` 全套 + `t313` + `T312_FINAL_SUMMARY.md` + `PHASE4_ADMISSION_RESOLUTION.md` 打上「作废 / 无出处 / 待重写」批注（保留留痕不删除）；撤回报备附件；**停止一切"已准入 / 6 个月跟踪中"对外表述**
2. **门禁 P0 四件套落地并跑通真实路径**：MDD 上限门禁 / 文档↔产物一致性门禁 / 压测有效性门禁 / 引用路径存在性门禁 + 把 `SKIP` 移出 `is_pass`。判据：对权威产物运行 → MDD 门禁判 **FAIL**、一致性门禁对 92.51% 判 **FAIL**、空 context 下**不再打印"全绿"**
3. **定位复现性缺陷**：查清「同一 `params_hash` 四份产物三种结果」的根因（数据快照 / 暖机窗口 / 未入哈希的输入）。这是所有后续结论的地基

`M1 止血` → `M2 复现性闭环` → `M3 门禁 P0 落地` → `M4 文档口径统一` → `M5 合规包重写` → `M9 Phase 4 准入重审` → `M10 重启模拟盘`
