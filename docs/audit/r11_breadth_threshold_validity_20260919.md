## 三、25% 边界的稳定性（「低宽度零仓」的依据）

| 检验 | 结果 |
|---|---|
| 逐年（高侧>低侧） | **8/10 年同向**（反例 2020/2021 疫情 V 反） |
| 五年两段差 | 前半 +1.749%、后半 +0.503%（同向，强度衰减） |
| **25% 处跳变逐年复现** | **7/8 年为正** |
| 细分 1.5pp 带 | 单调递增、**无跳变**（−0.67→−0.67→−0.38→+0.17→+0.75） |
| PBO（简化，200 次随机 50/50） | **0.0**（判据 ≤0.5，理想 <0.3） |

### 诚实标注：简化 PBO 的退化

本次 PBO 实现中，IS 最优阈值 **199/200 次都选了最高阈值 0.35**——因为
「b≥th 的条件均值」对 th 单调递增，选最大必最优。故 PBO≈0 只证明
**阈值序关系稳定**，⛔ **不构成「0.25 这个点最优」的证明**；
后者由「逐 1.5pp 细分 + 逐年跳变复现」两项支持。

## 四、对 e11-linear 失败的精确归因（修正前一版结论）

前一版中间发现（`e11_linear_interim_finding_20260919.md` §二）把 e11 的
退化归因为「mid 带平均暴露 +6.76pp」。**本文补上更精确的机制**：

linear 的权重函数 **w(b) 在 [0.25,0.35) 单调递增**（0→1.0）；
而收益对 b 的关系是 **W 形**（30-35% 是 dead zone）。

⇒ **单调递增的权重，恰好把仓位重心压在局部坏带 30-35% 上**：

| b | linear cap | 该 b 附近前瞻5日 | 后果 |
|---|---|---|---|
| 0.25 | 0% | +0.54% | 好区但空仓（少赚） |
| **0.30-0.35** | **50%→100%** | **−0.69%** | **重仓在坏区（亏钱）** |
| ≥0.35 | 100% | +0.05~+0.84% | 正常 |

而 hard + mid_cap=0 在整个 [0.25,0.35) 给 0 仓 ⇒ **天然规避该坏带**。

**结论：e11 的失败不是「暴露增加」本身，而是「权重函数单调性方向与
收益的 W 形结构相冲突」**。这也解释了 round_trips 翻倍（156→312）与
MDD +7pp（在坏带重仓 + 下跌途中不立即清零）。

## 五、对 C1/C7 的裁决影响

1. **信号层有效**（25% 边界 7-8/10 年稳定）⇒ Hermes「病在接口不在信号」
   的判断**在本仓得到实证支持**；
2. **但「连续化」不等于「单调斜坡」**：本仓实测表明正确方向**不是**把
   台阶换成单调斜坡（e11 已证负），而是——若要做连续化——需允许
   **非单调权重**（在 25-30% 给仓、30-35% 减仓）。
   ⚠️ 这有**曲线拟合风险**：25-30% 桶仅 166 天、30-35% 桶 168 天。
   任何非单调权重**必须预登记 + PBO/WFA 检验**，否则就是给噪声画曲线。
3. **C7 判据分层**（本仓标定建议）：
   - 信号层：PBO/DSR（阈值序关系稳定性）；
   - 构型层：平台宽度（回测 CAGR 对阈值的敏感性）；
   - 两层结论可不同，⛔ 不许互相替换（本案即是实例：信号层 PBO≈0、
     构型层无平台）。

## 六、诚实边界

1. 「池内等权前瞻收益」是**择时层proxy**，非策略实际持仓收益（策略持 3-8 只
   高分票，与 487 只等权不同）；
2. 前瞻 5 日**重叠样本**（每日滚动）⇒ 有效样本数远小于 2426，
   本报告未做 Newey-West 类修正 ⇒ 显著性是**上界口径**；
3. 25-30% 与 30-35% 两个桶各约 170 天（≈8 个月），W 形结构
   **可能部分是样本噪声**；须 WFA/子样本复核后才可作为规则使用；
4. 本报告不推翻 e11 的预登记裁决（代价过大），只修正其归因。
