## 二、裁决（按预登记 §四 第三档）

e13a=7.13% ∈ (6.82%, 8.08%) ⇒ **两因素各有贡献**，恒等式分解：

```
exposure_effect = e8b − e13a = 8.5814 − 7.1312 = −1.4502pp（暴露代价 ~64%）
shape_effect    = e13a − e11 = 7.1312 − 6.3196 = −0.8116pp（形态代价 ~36%）
合计            = −2.2618pp  ≡  e8b→e11 实测总差 −2.2618pp ✓ 恒等式逐值成立
```

恒等式容差 ±0.3pp 内逐值闭合 ⇒ **无交互项**，分解干净。

附属判据核对：MDD 21.44% ∈ [17.40%,24.40%] 预期带 ✓；换手 5.71 <6.5
容差内（高于 e8b 系 mid 带实际持仓的路径效应，trips 308 与 e11 的 312
同量级——持仓位即有换手）；CAGR 落档无需异常登记。

## 三、结论与方向推论

1. **暴露增加是主因（64%）**：mid 带加仓 6.8pp 平均暴露亏 1.45pp，
   再次坐实「警戒区零仓」与「mid 带负 alpha」既有裁决。
2. **单调斜坡形态本身亦有害（36%）**：同暴露下斜坡比平台多亏 0.81pp——
   与 R11 W 形归因精确一致（linear 在 [0.25,0.35) 单调递增 ⇒ 仓位重心
   压在 30-35% dead zone；平台 50% 均摊重心更靠左）。
3. **对连续映射方向的约束（登记）**：「暴露中性的连续映射」最多只能
   收复暴露段 1.45pp；形态段 0.81pp 要求权重函数在 dead zone **非单调
   减重**——按 R11 纪律：任何非单调权重 ⇒ 预登记 + PBO/WFA
   （25-30%/30-35% 两桶各仅 ~170 天，曲线拟合风险已登记）。
4. **e13a 定位**：归因对照臂，非晋级候选（mid 带加仓方向与「警戒区
   零仓」裁决相反，CAGR 7.13% < e8b 8.58% 本在意料内——它的价值
   在分解而非晋级）。 <!-- gate-doc-ignore: 历史快照（消融实验实测值，非基线声明），⛔ 不改史 -->

## 四、诚实边界

- 暴露口径为日度目标仓（§五预登记同一口径），与回测实际持仓暴露
  存在路径差（节拍/T+1/计息），0.04pp 等价差即源此口径；
- 分解为**本构型局部结论**（d=0.25/a=0.35 邻域），不外推至全参数面；
- shape_effect 归因的是「linear 这一特定斜坡」vs「平台」，不是
  「连续 vs 离散」的全称判决——非单调连续形态未被本实验覆盖。
