## 一、臂阵（4 臂 + 安慰剂，Bonferroni）

| 臂 | 事件集 | 方向先验 |
|---|---|---|
| P1 | 目标价上调：同机构×同股相邻研报 aim_mid 变化 ≥+10% | 正 |
| P2 | 目标价下调：同机构×同股相邻研报 aim_mid 变化 ≤−10% | 负 |
| P3 | 隐含空间极端：aim_mid/close_T0 − 1 截面 top20% | 负（过度乐观均值回归） |
| P4 | 首次目标价覆盖：该股 180 日内首条含 aim 研报 | 正（弱） |
| P5 | 安慰剂：同批事件 T0 随机错配 ±30td | ~0 |

aim_mid=(indvAimPriceT+indvAimPriceL)/2；仅 T 或仅 L 非空时取
非空端。T0=研报发布日，T+1 收盘入场（同 e49 口径），
h∈{1,5,10,20}，基线=同日截面均值。同股同日多条取变动最大者；
同股 20td 去重。

## 二、判定门（同构骨架）

- 判「强」：|t_cluster|≥2.6 + 方向合先验 + 年一致性≥60% + n≥300。
- 可成交性切片：判强者必跑剔除 T+1 涨停/停牌后残余；残余 <50%
  → 降「判强不晋级」。
- 稀疏性：P1/P2/P4 单臂年事件量 <300 → INCONCLUSIVE 如实标注
  （不可与"判负"混淆）。

## 三、范围

- P1/P4 判强且切片存活 → 事件做多候选（与 e49-A1 关联度检查，
  评级上调+目标价上调同报高共线 → 合并登记不重复计）。
- P2 判强 → veto 候选（同 e49-A4/K 族方向）。
- P3 判强 → 拥挤度/降温指标候选。

## 四、已知局限

- 目标价覆盖偏大盘蓝筹（机构优先覆盖权重股），截面风格偏斜
  如实披露；
- indvAimPrice 为东财解析值，存在异常值（>5×现价按脏值剔除，
  剔除率如实登记）；
- 2017 起覆盖（EM 深度上限），无 2015-16 段——覆盖期 <5 年
  门按降级标注执行。
