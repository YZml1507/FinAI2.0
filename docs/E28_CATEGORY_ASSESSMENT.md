## 二、为什么判强仍不直接立项

| 检查 | 实测 | 含义 |
|---|---|---|
| 多头端超额 | S1 0.04%/S4 0.03%/S6 0.11%/S2 0.28%/S5 0.30% 每月 | 价差大头在空头侧（户数激增股跑输）；long-only 只能捕获 Q_top excess |
| 净边际 | S2/S5 ≈3.3–3.5%/年毛利 − 成本 ≈ 滑点误差带边缘 | 与 e26-M5 同量级尴尬：有方向、没余量 |
| 反向因果 | S3（户数降×涨势交互）t=−1.01 判负 | 「户数降=吸筹」叙事不成立；信息集中在「激增→回避」剔除侧 |
| 信号冗余 | S1/S2/S4/S5/S6 同源（holders 序列变换），截面相关必然高 | 5 个「强」不等于 5 份独立 alpha |

## 三、裁决

1. **不立项独立引擎策略**（同 e26 判词：净边际不足覆盖散户费率下的
   执行不确定性）。
2. **候选因子库 +2**：`S5 holders_z4`、`S2 consec_down` 入库（与 M5、
   E25-F6、E23-H2 并列）。重启触发条件沿用 e26 §三：跨族低相关 +
   第二个独立族「强」或行为轴数据交叉验证。
3. **新增衍生用途候选**：户数激增剔除过滤器（风控侧 veto，非 alpha 侧）
   ——对持仓池剔除「近季户数环比 > +30%」个股。该用途不是影子假设族，
   不走预登记族筛选；如启用须在引擎侧单独做 A/B 验证并登记。
4. **族间相关性待办**：S5 与 M5（e26）截面相关实测待 margin_detail
   数据在机时补算（当前 margin 目录空，重采需 akshare 采集器 ~小时级）。
