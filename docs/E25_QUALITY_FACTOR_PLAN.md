## 二、研究问题

两个**独立且互补**的问题，对应两个宇宙面板：

- **Panel P（池内倾斜）**：在 692 c3_universe 红利池内，质量/价值倾斜能否在
  高息候选中再选出更好的票？——部署相关问题（若成立，e26 进引擎改造 e8b 选股层）
- **Panel F（全 A 探索）**：e23 未覆盖的基本面/价值因子在全 A 截面是否有
  截面预测力？——科学问题（若成立，开启非红利策略路径，须另行评估）

⛔ 两面板不是互相备份——任一成立都走各自分支，都不成立则如实关闭。

## 四、假设清单（方向先验，各只允许一个回看参数，⛔ 不搜参）

### Panel P：池内质量/分红质量倾斜（8 假设）

| # | 假设 | 构造 | 方向 | 依据 |
|---|---|---|---|---|
| P1 | ROE 水平 | 最新已公告 `roe` | 多高 | 质量因子经典定义；池内分红持续性应与 ROE 相关 |
| P2 | ROE 稳定性 | 近 8 季 `roe` 序列标准差 | 多低（波动小=优） | 「分红陷阱」多来自盈利波动大的票 |
| P3 | 盈利质量 | `deducted_net_profit_yoy` − `net_profit_yoy`（扣非−报表增速差，大=扣非更实） | 多高 | 报表增速靠非经常损益撑的是伪质量 |
| P4 | 低杠杆 | `debt_to_assets` | 多低 | 高杠杆高息股是分红陷阱重灾区 |
| P5 | 现金含量 | `cash_flow_per_share` | 多高 | 分红须现金流支撑 |
| P6 | 分红连续性 | 近 5 自然年有分红记录的年数（dividend_events） | 多高 | 「连续多年分红」是红利指数通用入选条件 |
| P7 | 分红增长 | 最近年度 `cash_div` 对上一年度同比 | 多高 | 分红增长 > 分红水平的一次差分信号 |
| P8 | 盈利增长一致性 | 近 8 季 `net_profit_yoy > 0` 的季数占比 | 多高 | 稳定正增长 vs 大起大落 |

### Panel F：全 A 未测因子族（8 假设）

| # | 假设 | 构造 | 方向 | 与 e23 的关系 |
|---|---|---|---|---|
| F1 | 低 PE | `pe`（数据自带，亏损股按字段原值，缺失如实计） | 多低 | e23 未测——经典价值 |
| F2 | 低 PB | `pb` | 多低 | e23 未测 |
| F3 | ROE 水平 | 同 P1 | 多高 | e23 未测 |
| F4 | 低杠杆 | 同 P4 | 多低 | e23 未测 |
| F5 | 盈利质量 | 同 P3 | 多高 | e23 未测（H5 是扣非**增速**本身，非增速差） |
| F6 | ROE 稳定性 | 同 P2 | 多低 | e23 未测 |
| F7 | 现金含量 | 同 P5 | 多高 | e23 H6 是 CFPS/**价**（收益率口径），本假设是 CFPS 水平——如实登记为邻近假设 |
| F8 | 盈利增长一致性 | 同 P8 | 多高 | e23 未测 |

**与 e23 的重叠声明**：P 面板的宇宙不同（池内条件化 vs 全 A），属新问题；
F 面板中 F7 与 e23-H6 构造不同（水平 vs 收益率），其余 7 个均为 e23 未测空间。
⛔ 不重测 e23 已判负的假设——那是数据挖坟。

## 五、统计量与闸门（拟冻结）

- **统计量**：五分位组合。主指标 = Q_top − Q_bottom 非重叠月度 fwd20 价差；
  副指标 = Q_top − 全宇宙等权超额；稳健性指标 = 月度 Rank IC 均值与 IR
  （IC 不用于裁决，仅披露）。
- **G1**：价差序列 t ≥ 2.0（非重叠月，P 面板预期 M≈110+，F 面板 ≈110+）
- **G2**：年度价差符号一致 ≥ 60% **且**两半窗（2015–19 / 2020–24）同号
- **G3 成本**：Q_top 月度单边换手 × 0.30%（往返估）≤ 月均价差的 50%
- **G4 样本**（e23 教训修正版）：**信号有定义**的月份中，
  Panel P 有效样本 < 300 只 / Panel F < 1000 只的月份占比 ≤ 30%
  （P 池 ~600 只，五分组 ~120/组，300 是全池半数底线）
- **多重比较**：全计划 16 个假设一次性登记。
  - **「强」**：t ≥ 2.85（≈Bonferroni 16 单侧 5%）且 G2/G3/G4 全过
  - **「弱」**：2.0 ≤ t < 2.85 且 G2–G4 全过——仅登记，不追加
  - 其余判负

## 六、分支决策树（多路设计，⛔ 一条路走不通即走预案，不允许死磕）

```
Panel P + Panel F 首轮筛选（16 假设，一次性）
        │
        ├─ 任一面板出现「强」
        │     ├─ P 面板「强」 → 路径 A：e26 引擎预登记
        │     │      （e8b 选股层注入质量倾斜，无择时/有择时双臂，
        │     │        对照 = e8b + 510300 + 512890 同窗；判据届时另立）
        │     └─ F 面板「强」 → 路径 B：非红利策略可行性评估会
        │            （宇宙/成本/容量重估，先出评估文档再决定是否立项，
        │             ⛔ 不直接进引擎——红利池外的策略是范畴变更）
        │
        ├─ 无「强」但同一面板内 ≥2 个「弱」
        │     → 路径 C：合成臂一次性测试（z-score 标准化等权合成，
        │        每宇宙至多 1 臂，同套双闸裁决；合成仍不达「强」→ 判负关闭）
        │
        └─ 全判负（含合成臂）
              → 路径 D：如实关闭并登记——
                结论 = 「本数据面上的质量/价值因子族无可用截面 alpha」，
                交付建议维持 e20 裁决：512890 红利低波 ETF beta 持有，
                本项目研究面正式关闭（除非有新数据源进场）
```

### 明示不重试的死路（避免沉没成本漂移）

- ⛔ **择时/宽度参数再搜**——e15–e19+e20 已多次判负，不在任何分支内重开
- ⛔ **红利族内参数再调**——e16/e17 六臂全负，判据不放宽
- ⛔ **ETF 择时叠加**——e15 实测择时在 ETF 上同样无 alpha
- ⛔ **2025+ 数据做任何形式使用**——永久 OOS 裁判席，摸都不摸
- ⛔ **事后调阈值/换分位/改回看**——任何「差一点点就过」的假设只登记不重跑

## 八、已知风险与如实披露

1. **池内截面薄**：P 面板五分组仅 ~120 只/组，功效低于全 A——若 P 全负而 F 有正，
   如实解读为「池内质量分散度不足」，不反向外推。
2. **质量因子在 A 股的文献证据本就弱于美股**：判负是合理先验内结局。
3. **多重比较修正偏严**（16 假设）：宁可漏检真实弱信号，不可放进假信号——
   「弱」档的存在就是为合成臂留的合规出口。
4. **财报字段覆盖爬坡**：2015 年前后 `financial_pit` 覆盖率可能爬升——
   G4 修正版只计信号有定义月，如实登记覆盖缺口形态。
5. **与既有 veto 层的关系**：若 P 面板证明质量排序有 alpha，e8b 的
   `use_quality_veto` 二元否决可升级为连续倾斜——但那是 e26 的事，本方案不预支结论。
