# E50 veto 层扩展评估预登记（冻结版）

> 冻结时间：2026-09-21（先于扩展 veto 序列的引擎 A/B 运行）。
> 承接：e48 K2/K3/K5 判强 + 重叠率 24.5% → V4 函件 veto 候选；
> e37promo 教训记牢：G-1 留出增量翻负是 veto 晋级失败的死因，
> 本评估沿用同一电池骨架，**V4 单独算增量**（不与 V1-V3 混）。

## 一、V4 定义（冻结）

V4 = {sev≥2 函件（关注函/警示函/监管函）} ∪ {任类函件 30 自然日
内 ≥2 封}，禁买窗 = 事件日起 20 交易日（事件日当日已不可买入
假设——盘后公告口径；函件若为盘中披露则当日起禁）。
扩展序列 veto_daily_ext = V1∪V2∪V3∪V4 逐日合并。

## 二、臂阵（7 臂，mirror e37promo/e44 骨架）

| 臂 | 构型 |
|---|---|
| verify-off | 冠军 hard（复现锚） |
| v123 | e8b+既有 veto（复现 e37 收单 9.1414/17.4709） |
| v1234 | e8b+扩展 veto（主评估臂） |
| g1-v1234 | 2021-01-01 起留出半窗 |
| g1-v123 | 同上既有 veto 对照（Δ 归因分离） |
| g3-v1234-fee2 | 费率×2 |
| g2-v1234-a315 | 阈值扰动 0.315（悬崖互测） |

判定门：
- v1234 判「有效增量」：ΔCAGR(v1234−v123) ≥ +0.1pp 且
  ΔMDD ≤ +0.5pp；
- G-1：v1234 留出段 ΔCAGR(v1234−v123) 不翻负（≥0）；
- G-2：a315 下 v1234 相对 v123 的增量不为更差交互；
- G-3：费率×2 下 v1234 增量仍 ≥0。
- 增量全门过 → V4 晋级 veto 集合（veto 层本身仍受 e37promo
  裁决约束：veto 层不晋级，V4 只进「候选 veto 扩展」档）；
- 任一门破 → V4 留候选库原级，不进引擎。

## 三、纪律

- veto 扩展不改变选股/择时层；只加禁买集合。
- 函件数据 2024H2 断崖（监管口径变更）→ 2025+ OOS 观察
  段对 V4 天然失真（无函件≠无函件签发），如实登记：
  OOS 段不作为 V4 有效性证据，只看不扣分。
- 名册：veto_daily_ext.parquet 构建脚本入库，重建可复现。

## 四、已知局限

- 禁买窗 20td 冻结；窗长敏感性和「函件已 price-in」结构
  属诊断位不做搜参。
- veto 股票与持仓交集只在调仓节拍生效（引擎语义）——
  事件中途的既有持仓不被强制卖出，增量效应打折属预期。

## 五、收单（2026-09-21 电池完成）

**结果：V4 增量门未过——池内零增量，如实判负。**

| 臂 | CAGR | MDD | rt |
|---|---|---|---|
| verify-off | 8.58% | 17.40% | 156（锚逐位复现） |
| v123 | 9.14% | 17.47% | 155（e37 锚复现 ±0.000） |
| v1234 | 9.13% | 17.47% | 155 |
| g1-v123 / g1-v1234 | 12.35% | 12.38% | 57（两臂逐值相同） |
| g2-a315-v1234 | 6.05% | 29.20% | 182（悬崖同 hard） |
| g3-v1234-fee2 | 8.35% | 17.78% | 149 |

Δ(v1234−v123) = **−0.01pp / +0.002pp / rt 同**——函件 veto 在
487 红利池内增量为零；G-1 两臂逐值一致证实 V4 在池内
几乎从未触发。

**归因（如实）**：veto_ext 日均禁买集合 397 只（base 309）
但池内命中率近零——监管函件标的多为小盘绩差股，487 红利
池（连续分红+流动性过滤）天然与之不相交。**V4 的价值域在
全 A 宽域组合/风险过滤层，不适配 e8b 宇宙。**

**裁决**：V4 不晋级 e8b 引擎（增量门 −0.01pp<+0.1pp）；
保留候选库 veto 侧条目，标注「池内无效，宽域待载体」——
若未来出现宽域组合构型（非红利池）再评估。
函件数据资产保留（proxy 推断件可用于 2025+ 段监控口径）。
