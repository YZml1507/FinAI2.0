# E62 预登记 —— 公告正文 NLP 因子族（body_nlp）

> 预登记冻结：在 `--run` 任何实验前，先定义信号口径、判据、必过门禁。
> 数据来源：``data/notice_body/{year}.parquet``（atype 白名单正文，
> 采集进行中，本文件起草于 2026-09-23 覆盖尚不完整——**缺口登记见 §6**）。

## 1. 假设与依据

公告文本携带两类可机器提取的信息：
- **披露风格**：文本长度/段落结构——披露冗长异常可能对应隐瞒复杂度
  （负向）或主动合规澄清（中性偏正）；
- **情绪/语调**：风险词密度、正面词密度——财报/诉讼/监管类公告
  的措辞方向与后续漂移（PEAD 类）相关。

文献对照：A 股公告 NLP 证据弱于美股（中文分词噪声 + 公告模板化），
故阈值设中等（t≥3 判强线不变，预期区间 t 1.5–3.5）。

## 2. 信号定义（逐股 × 月度聚合，窗口 60 日滚动）

| 信号 | 构造 | 方向假设 |
|---|---|---|
| `nlp_loglen` | 近 60 日公告正文 log(字符数) 均值 | 未定向（探索） |
| `nlp_ann_cnt` | 近 60 日公告条数 | 高频披露=信息事件密集，未定向 |
| `nlp_risk_den` | 风险词命中数/千字（风险词表见 §4） | **负向**（风险披露↑ → 后续收益↓） |
| `nlp_pos_den` | 正面词命中数/千字 | **正向弱** |
| `nlp_lit_frac` | 诉讼/仲裁/处罚/问询/关注函/监管/立案/违规/警示类公告占窗口内白名单公告比例 | **负向** |

聚合口径：逐股近 60 自然日窗口；无公告股记 NaN（非 0）；
横截面 z-score 标准化；去市值中性化作为次级变体一并登记。

## 3. 判据（判强线，与既有族同尺）

- **判强**：月频 IC ≥0.04 **且** t ≥3，且去市值后 t 不塌到 <2；
- **判弱**：t <2 或 IC <0.02——登记关闭不追；
- **灰区**：t∈[2,3)——只允许一个 follow-up 变体（换窗口或去市值口径），
  二轮仍不达线则判弱。

## 4. 实现要点（防自欺）

- 词典：风险词表/正面词表在脚本内显式登记（中文词表 + 正则命中计数）；
  ⛔ 不许用现成英文金融词典直译——模板化措辞会污染。
- PIT：`ann_date` 为披露日，窗口聚合严格 ≤T；公告正文本身无修订风险。
- 安慰剂门（事件族纪律）：随机日期错位 ±20 日重算 IC，真实 IC 必须
  显著高过安慰剂分布（p<0.05）。
- 池内命中率前置门：信号高分组落在可交易池（非停牌/ST/次新 <60 日）的
  占比须 ≥70%，否则 alpha 不可执行。
- 覆盖度登记：正文采集完成率 <80% 的区间标注为"部分覆盖"，
  结论按偏保守解读（缺失偏向无公告股）。

## 5. 流程门（必填）

1. 本文件 commit 后再跑实验（prereg freeze）；
2. 实验产物：IC 表 + t 值 + 安慰剂分布 + 命中率 → `docs/E62_BODY_NLP_RESULT.md`；
3. 判强才晋级为候选轴入 tracker；判弱/灰区登记关闭。
