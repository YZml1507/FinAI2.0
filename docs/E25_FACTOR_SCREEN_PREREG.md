## 四、统计量与闸门（冻结）

- **统计量**：五分位组合（每组 = 当月有效样本 //5，两端各一组）。
  主指标 = Q_top − Q_bottom 非重叠月度 fwd20 价差；
  副指标 = Q_top − 全宇宙等权超额；披露 = 月度 Rank IC 均值/IR（不入裁决）。
- **G1**：价差序列 t ≥ 2.0
- **G2**：年度价差符号一致 ≥ 60% 且两半窗（2015–19 / 2020–24）均值同号为正
- **G3 成本**：Q_top 月度单边换手 × 0.30% ≤ 月均价差的 50%
- **G4 样本**（e23 修正版）：在**信号有定义**（当月有效样本 ≥5）的月份中，
  Panel P 有效样本 < 300 或 Panel F < 1000 的月份占比 ≤ 30%
- **多重比较**：16 个假设一次性登记。
  - **「强」**：t ≥ 2.85 且 G2/G3/G4 全过
  - **「弱」**：2.0 ≤ t < 2.85 且 G2/G3/G4 全过（仅登记不追加）
  - 其余判负；当月 fwd/信号不可得致有效月 < 60 → **INCONCLUSIVE** 如实登记
- **合成臂（条件触发）**：同一面板内 ≥2 个「弱」及以上 → z-score 截面标准化
  等权合成信号 1 臂（不重复回看、不重新选方向），同套闸门裁决；合成臂
  不计入首轮 16 个多重比较基数（条件性追加如实披露）。

## 五、分支决策（冻结）

- P 面板任一「强」 → **e26 引擎预登记**（e8b 选股层质量倾斜，±宽度择时双臂，
  对照 e8b/510300/512890；判据届时另立）
- F 面板任一「强」 → **非红利策略可行性评估会**（宇宙/成本/容量重估，先出
  评估文档，⛔ 不直接进引擎）
- 无「强」有「弱」→ 合成臂一次性测试（见 §四）
- 全判负 → 如实关闭，维持 e20 裁决的 512890 建议，研究面关闭

**明示不重试**：择时/宽度参数再搜（e15–e20 判负链）；红利族内调参（e16/e17）；
ETF 择时叠加（e15）；2025+ 数据任何形式使用；事后调阈值/分位/回看。

### 如实登记

- **注 a（G4 结构性判负）**：Panel P 全假设 `g4_low_frac=1.00`——
  `pool_yearly` 各年成员 21–274 只（十年并集 692），**任何月份都不可能
  ≥300**，G4-P 阈值事前不可过。P2 统计面达标（t=2.76、G2/G3 过）仍按
  冻结判据判负——此为「池内截面太薄、五分位篮仅 4–55 只、结论本就不可
  靠」的门禁本意兑现，⛔ 不构成事后放松理由，亦不回溯调阈。
- F6「弱」孤例如实登记（ROE 近 8 期标准差，全 A 截面，月均价差 +0.36%、
  年度一致 0.9、换手 5.7%）；单假设孤证 + 未过 Bonferroni 强阈，
  不构成晋级依据。
- 财报陈旧度诊断：月均 **10.3%** 截面最新公告龄 >180 自然日（诊断项，
  非闸门；退市/长期未公告票如实留存）。
- 剔除计数：除权跳空 4934 格、|r|>0.21 超限 5688 格（与 e23 同窗同口径）。
- Panel P 各月有效样本中位 153 只（n_min=0：个别月初池成员有效样本 <5，
  如实计为信号未定义月，不作 G4 分母）。
- fwd 窗 NaN 填充占比均值 ~5.5%（停牌/退市缺口按 0 收益复合，同 e23 口径，
  低估含派现/停牌票收益的既有偏差如实保留）。
