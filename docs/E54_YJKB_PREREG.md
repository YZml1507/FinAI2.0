# E54 业绩快报「真超预期」事件族预登记（冻结版）

> 冻结时间：2026-09-22（先于任何筛选运行）。
> 数据源：`data/forecast_em/yjkb/{period}.parquet`（业绩快报，
> 公告日期=PIT 锚，净利润-同比增长列已验）+ `yjyg/`（预告，用于
> 「同股同报告期是否存在在先预告」判定）。
> 区别于 e43：e43 测预告类型方向；本族测**快报相对预告的
> 信息增量**——核心假设=无在先预告的快报才是真超预期事件。

## 一、臂阵（5 臂，Bonferroni）

| 臂 | 事件集 | 方向先验 |
|---|---|---|
| K1 | 快报净利同比 ≥+50% 且同股同报告期**无在先预告** | 正（真惊喜） |
| K2 | 快报净利同比 ≥+50% 且**有在先预告** | 正弱于K1（已消化对照） |
| K3 | 快报净利同比 ≤−50% | 负（veto 候选方向） |
| K4 | 快报净利同比 ≥+50% 且在先预告为负类(预减/首亏/续亏/略减/增亏) | 正加强（预期反转） |
| K5 | 随机安慰剂门 | ~0 |

T0=快报公告日，T+1 收盘入场，h∈{1,5,10,20}，基线=同日截面
均值。同股同报告期多条快报取最早；同股 20td 去重。
筛选窗 ≤2024-12-31。周期匹配键 = ts_code × end_date(文件名期次)。

## 二、判定门（同构骨架）

- 判「强」：|t_cluster|≥2.6 + 方向合先验 + 年一致性≥60% + n≥300。
- **可成交性切片**：判强正臂必跑剔除 T+1 涨停/停牌后残余；
  残余 <50% → 判强不晋级。
- **落池率前置门**：判强负臂先算事件×487 池命中率；
  <8% → 宽域待载体登记（e50/e52 标准）。
- K1 vs K2 的差值是「真惊喜增量」的检验：若两者相当，
  「无预告」机制不成立，如实披露。

## 三、范围

- K1/K4 判强且切片存活 → 事件做多候选评估（净边际+篮宽）；
- K3 判强 → veto 候选登记。

## 四、已知局限

- EM 快报库对退市股同样剔除（与 yjyg 同库），负臂偏保守
  如实披露；
- 「无预告」判定依赖 yjyg 完备性（其本身缺退市股）→ K1 集
  可能混入「预告缺失是因退市未收录」的样本，方向偏保守；
- 快报覆盖期以 manifest 为准（2015 起）。
