> 事件在 A 股有正向漂移（PEAD 的分析师版）。

## 一、臂阵（6 臂，Bonferroni）

| 臂 | 事件集 | 方向先验 |
|---|---|---|
| A1 | 评级上调（任何→买入/增持，或评级分上调） | 正 |
| A2 | 评级下调（任何→中性/减持，或评级分下调） | 负 |
| A3 | 盈利预测上调（预测净利环比上修 >10%） | 正 |
| A4 | 盈利预测下调（环比下修 >10%） | 负 |
| A5 | 多机构共振：30 日内 ≥3 家上调 | 正加强 |
| A6 | 随机安慰剂门 | ~0 |

T0=研报/预测披露日，T+1 收盘入场，h∈{1,5,10,20}，
基线=同日截面均值。同股同日多条取评级变化最大者；
同股 20td 内重复事件去重。筛选窗 ≤2024-12-31。

## 二、判定门（同构骨架）

- 判「强」：|t_cluster|≥2.6 + 方向合先验 + 年一致性≥60%
  + n≥300。
- **可成交性切片（标准流程，e43 元教训）**：判强者必跑
  剔除 T+1 涨停/停牌事件后的残余效应；残余 <50% 原效应
  → 降「判强不晋级」。
- 覆盖期 <5 年或退市股缺失 → 如实降级标注。

## 三、范围

- A2/A4 判强 → veto 候选（同 K 族方向）；
- A1/A3/A5 判强且可成交切片存活 → 事件做多候选（净边际+
  篮宽评估；稀疏性大概率仍指向袖珍仓形态——e41 教训：
  稀疏事件族直接评估可成交切片而非先立袖珍仓）。
