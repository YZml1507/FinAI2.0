## 一、 阶段二核心目标与实现成果

依据《17_中低频量化研发防伪与工程质量门禁体系深度调研报告》规划，阶段二将阶段一构建的六维独立门禁工具包（D-L-E-A-S-G）深度挂接至主回测流程 scripts/run_dividend_backtest.py 中，实现非侵入式装配与严格的 **Fail-Closed 机器防伪阻断**。

### 1. 前置闸门（Pre-run Gates）
- **挂接位置**：在数据预载与股票池准备完毕后、回测引擎执行前。
- **涵盖门禁**：
  - **D-1 原始日线跳变率检验**：扫描所有输入日线，杜绝后复权脏数据与异常跳变（完美兼容送转停牌复牌与 IPO 前 5 日物理特征）；
  - **D-2 流通市值与成交额偏离度检验**：检验全池市值分布标准差（Std > 100 亿）与成交额偏离度，杜绝成交额充当市值；
  - **D-3 Point-in-Time 动态股息率检验**：校验逐日滚动股息率变异种数（>= 50 种），彻底阻断全年常数静态均值未来函数；
  - **D-4 停牌日成交量为零检验**：杜绝停牌日前值平推脏成交；
  - **D-5 高价股与整手约束检验**：约束委托价格 <= 300 元且股数为 100 整数倍；
  - **L-1 特性存活前置审计**：检验回测必需配置（如 DIVIDEND_TAX 扣费开启）；
  - **L-3 关键风控与调用链路审计**：源码 AST 静态扫描，杜绝关键逻辑被注释或绕过。
- **阻断行为**：任一前置门禁失败，立即抛出 GateBlockerError，终止回测，不启动撮合引擎。

### 2. 后置闸门（Post-run Gates）
- **挂接位置**：在撮合引擎执行完毕、绩效指标计算完成之后，向 ExperimentRegistry 登记落盘（registry.record_run）之前。
- **涵盖门禁**：
  - **E-1 5 必挂极限用例通过率检验**：涨停买拒、跌停卖拒、停牌拒、除权连续、T+1 隔日卖；
  - **E-2 送转拆股 FIFO 份额一致性**：防缺股崩溃，全额清仓持仓精确为 0；
  - **E-3 滑点推移价格涨跌停限幅检验**：买入成交价 <= limit_up，卖出成交价 >= limit_down；
  - **A-1 七科目费用逐笔分厘平衡检验**：各科目求和与账本总扣除差额绝对值 strictly 0.00 元；
  - **A-2 每日资产现金流守恒检验**：逐日现金收支与手续费、分红入账、红利税严格守恒，未解释差额 strictly 0.00 元；
  - **A-3 10 万元往返黄金算例检验**：标准往返费率严格处于 95~125 元 A 股真实区间；
  - **A-4 历史分段费率时序穿透检验**：2023-08-28 前卖出严格执行 1‰ 印花税，杜绝穿越历史少扣税；
  - **S-1 年化单边换手率硬顶检验**：年化单边换手率严格 <= 400%，防 5 元佣金地板暴击；
  - **S-2 破 MA200 择时空仓生存检验**：熊市跌破 MA200 期间持仓比例严格 <= 5%；
  - **S-3 散户流动性容量与滑点抗压测试**：单笔委托 <= 2% ADV，滑点 +50% 扰动后年化收益非负；
  - **S-4 红利税避税锁定期检验**：20% 惩罚性红利税占总分红比例严格 <= 20%；
  - **S-5 收益归因证据链与关税作弊自查**：成交非零时印花税与佣金严格非零，必须附带源码出处；
  - **G-1 交付出处三件套完整性检验**：Git SHA + Data Hash + Timestamp 缺一不可；
  - **G-2 tasks.md 物理勾选防伪签名**：机器门禁通过证据签名检验；
  - **G-3 母库只读区 FINDING- 守卫行数门禁**：行数严格恒等于 370 行。
- **阻断行为**：任一后置门禁失败，立即抛出 GateBlockerError，终止落盘，坚决拒绝向 experiments/runs/ 写入任何记录。

### 3. CLI 参数支持
- 默认：严格开启门禁（enable_gates=True, fail-closed）；
- 调试选项：支持 --no-gates 显式旁路开关（仅供极限本地调试，在生产环境明确告警）。
