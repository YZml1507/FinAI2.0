## 三、假设（草案 6 个，方向先验，⛔ 冻结后不搜参）

| # | 假设 | 构造（T 时点可见窗口内聚合） | 方向 |
|---|---|---|---|
| I1 | 高管本人净增持额/流通市值 | Σ(本人增持金额 − 本人减持金额) / circ_mv，近 60 日滚动 | 多高 |
| I2 | 高管本人增持广度 | 近 60 日有本人增持行为的高管人数（去重） | 多高 |
| I3 | 实控人/大股东减持压力 | Σ(大股东类变动人减持金额) / circ_mv，近 60 日 | 多低 |
| I4 | 净增持事件频率 | 近 120 日增持笔数 − 减持笔数（笔数非金额，抗单笔巨头） | 多高 |
| I5 | 增持价格相对强度 | 近 60 日增持成交均价相对当前价的溢价率 | 多高 |
| I6 | 增持连续性 | 近 120 日内发生增持的月份数（0-4 档） | 多高 |

方向依据：内部人净增持 = 知情资金流入 → 先验正；减持压力轴单独设臂（多低）。

## 四、统计量与闸门（同 e25/e26 骨架）

- 五分位组合；主指标 = Q_top−Q_bottom 非重叠月度 fwd20 价差；披露 RankIC。
- G1 t≥2.0；G2 年度符号一致 ≥60% 且两半窗同号；G3 换手×0.30% ≤ 价差 50%。
- G4：事件稀疏族按 e26 口径修正——信号有定义月（n≥5）中，
  n < max(200, 全 A 有效数×5%) 的月份占比 ≤30%（事件稀疏 ⇒ 绝对下限降到 200，
  五分位篮 ≥40 只；若实际覆盖不足如实登记，不放宽）。
- 多重比较：6 假设 Bonferroni「强」t≥2.6；「弱」2.0≤t<2.6；M<60 → INCONCLUSIVE。
- 合成臂：≥2 弱及以上 → z-score 等权 1 臂（披露不计基数）。
