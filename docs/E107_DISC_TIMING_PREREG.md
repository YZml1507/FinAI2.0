# E107 披露时点选择轴 PREREG（冻结于评估前）

## 数据
- 源：`data/cninfo_disclosure_schedule/{year}.parquet`（cninfo 定期报告预约披露表，259,397 行）
- 字段：F001D 报告期 / F002D 首次预约日 / F006D 最新(实际)披露日 / F003D-F005D 历次变更日（多 NaN）

## PIT
- `asof = F006D`（实际披露日确定可获得）；前视安全：只用 ≤ asof 已发生的事实构造信号

## 信号（事件→月频）
- `disc_late` = (F006D − F001D).days，报告期→披露日间隔（晚披露↔坏消息假设 → IC<0）
- `disc_resched` = (F006D − F002D).days，预约→实际推迟天数（推迟↔坏消息 → IC<0）
- 月频合成：当月有披露事件的股取当月最近一次值

## 假设
文献：A 股"早披露好消息"异象——晚披露/推迟披露公司后续跑输。

## 门禁
- 月频 Spearman IC ≥0.04 且 |t|≥3 判强晋级
- |t|<2 或 |IC|<0.02 判弱收单
- 安慰剂 ±20 日 p<0.05
- 2025+ 永久 OOS 只观察登记
