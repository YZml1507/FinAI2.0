- 判「强」：|t_cluster|≥2.6 + 方向合先验 + 年一致性≥60% + n≥300。
- 判强正臂必跑可成交性切片；残余<50% → 判强不晋级。
- 判强负臂先算×487 池命中率；<8% → 宽域待载体登记。
