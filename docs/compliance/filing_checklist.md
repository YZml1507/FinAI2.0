> **建立日期**：2026-09-02  
> **用途**：Phase 4 模拟盘期间（≥6 个月）逐项准备，Phase 5 实盘前提交  
> **依据**：11 号调研文档《A股程序化交易监管细则与个人报备实操指南》+ spec FR-COMP-1

---

## 0. 核心原则

**先报告，后交易**——未完成报备前，券商不得接受程序化交易委托（细则明确规定）。

报备免费、材料一次性填报、由券商代收代报；真正要做的是：
1. 理解四类异常交易行为（11 号 §5）
2. 确认距高频认定线有足够安全边际（11 号 §4）
3. 系统内置限速/计数/熔断/幂等四件套（11 号 §5.3）

- [ ] **报告表本身**（上交所官方 .xlsx，40 个字段分 5 组）
  - 官方直链：https://www.sse.com.cn/lawandrules/sselawsrules2025/trade/universal/c/10781705/files/fe60203af5bc459eb56cc1124f63f861.xlsx
  - 填报说明（.docx）：https://www.sse.com.cn/lawandrules/sselawsrules2025/trade/universal/c/10781705/files/5c50468ec61547c8a0d775f2a34d9f89.docx
  - 本地参考：11 号 §6.1 字段逐项说明

- [ ] **核心字段确认**（5 组 40 字段，重点关注）：
  - 基本信息：姓名、证件号、证券账户、报告类型（首次/变更/停止）
  - 资金信息：资金来源（自有）、规模（10-15 万）、杠杆情况（无）
  - **主策略类型**：红利 + MA200 择时（须与 T311 实现一致）
  - **辅策略类型**：市值加权（若有）
  - **账户最高申报速率**：≤5 笔/秒（系统硬限，距 300 笔/秒线两个数量级）
  - **账户单日最高申报笔数**：≤1000 笔/日（距 20000 笔/日线一个数量级以上）
  - **程序化交易软件名称及版本号**：如实填写（QMT/PTrade/自研框架）
  - **交易服务器所在地**：本地（家庭宽带，北京）或云端（如实）
  - **是否上传测试报告及应急方案**：是（对应必须项 1.6）

- [ ] **券商流程确认**：
  - 选定券商与通道（QMT 或 PTrade，11 号 §7.1 对比表）
  - 联系客户经理说明程序化交易需求
  - 券商审核报送 → 交易所备案 → 开通权限

**验收标准**：报告表填写完整、券商审核通过、收到程序化交易权限开通确认

### 1.6 风控措施说明
- [ ] **风控措施文档**
  - 核心内容（对应 11 号 §5.3 清单）：
    - **速率限制**：≤5 笔/秒硬限（系统强制，距 300 笔/秒高频线两个数量级）
    - **日计数器**：≤1000 笔/日硬限（距 20000 笔/日高频线一个数量级以上）
    - **熔断机制**：接近阈值时自动停止新申报 + 人工确认
    - **死循环保护**：同标的同方向重复报单去重、连续 N 次拒单即停机
    - **最小挂单存活时间**：≥5 秒（杜绝秒级挂撤）
    - **单票成交占比限制**：≤1% 该股同时段成交量（规避拉抬打压外观）
    - **MA200 择时保护**：指数低于 MA200 时空仓（T311 红利策略核心风控）
    - **止损规则**：组合管理器（T301）+ 择时退出
    - **异常处理**：停牌/涨跌停/断线重连前置拦截

  - **技术系统测试报告**（对应报告表字段"是否上传测试报告及应急方案"）：
    - 测试记录：524 离线单测报告（435 passed baseline）
    - 应急方案：断线重连、熔断触发、人工接管流程

## 4. 变更报备提醒（上线后持续维护）

根据细则**第十条**第二款（11 号 §3.4），报告信息发生重大变更时：

**时限**：下一个自然月的第 5 个交易日之前向券商提交变更报告

**常见重大变更情形**：
- [ ] 主策略类型/辅策略类型变更（如从红利策略改为趋势策略）
- [ ] 最高申报速率、单日最高申报笔数承诺值调整
- [ ] 技术系统更换（QMT ↔ PTrade ↔ 自研框架，版本大改）
- [ ] 交易服务器所在地变更（本地 ↔ 云端，搬家/换云商）
- [ ] 资金规模、杠杆情况重大变化
- [ ] 账户归属、联系方式变更

**操作流程**：
1. 变更发生后，记录变更日期与内容
2. 次月第 5 个交易日前联系券商提交变更报告
3. 券商收到后 5 个交易日内报交易所
4. 更新本清单对应项

## 5. 合规自查清单（实盘上线前最后核对）

根据 11 号 §5.3《个人系统自我合规检查清单》，逐项打勾：

### 速率与计数类
- [ ] 系统内置每秒申报+撤单上限（≤5 笔/秒）
- [ ] 系统内置单日申报+撤单计数器（≤1000 笔/日，逐日清零）
- [ ] 计数器接近阈值时自动熔断
- [ ] 撤单逻辑设置最小挂单存活时间（≥5 秒）

### 程序健壮性类
- [ ] 订单引擎有死循环保护
- [ ] 断线重连后不重复发单（幂等订单号）
- [ ] 停牌/涨跌停等状态委托被前置拦截
- [ ] 完整本地委托/成交/撤单日志留存（建议 ≥2 年，覆盖牛熊）

### 策略行为类
- [ ] 回测/模拟已统计真实报撤单笔数分布，与报备承诺一致
- [ ] 单票成交 ≤ 该股同时段成交量 1%
- [ ] 不在小市值、高波动、ST 类标的上跑大额动量策略
- [ ] 集合竞价阶段不做试探性挂撤

### 报备一致性类
- [ ] 报告表中策略类型与实际运行一致
- [ ] 实际申报速率、日笔数承诺值 ≥ 系统硬限
- [ ] 变更报备流程已建立（次月第 5 个交易日前提醒）
