## 变更报备触发条件（依据 11 号文档 §3.4）

需要**及时**提交变更报告的情形：

- [ ] 主策略类型变更（如从红利策略改为动量策略）
- [ ] 辅策略类型变更  
- [ ] 最高申报速率/笔数承诺值调整  
- [ ] 技术系统更换（如从 Python 换为其他语言/框架）  
- [ ] 交易服务器所在地变更（如从本地迁到云端）  
- [ ] 资金来源与规模、杠杆情况发生重大变化

**变更时限**：  
- 一般变更：5 个交易日内  
- 实质性变更：**事前报告**（如策略类型变更、系统更换）

## 注意事项

1. **先报告、后交易是硬闸门**：未完成报备，券商不得接受程序化委托（11 号 §1）  
2. **报备免费**：交易所不收费，券商代报通常也不收费  
3. **一次性填报**：报备通过后可持续运行，无需年审（除非触发变更）  
4. **低频策略优势**：月度调仓远离高频认定标准（5 笔/秒 × 300 秒 = 1500 笔/天），合规成本低  
5. **模拟盘数据是核心**：Phase 4 的 6 个月数据是报备材料的关键支撑
