## 2. 交易逻辑

### 2.1 选股逻辑

**股票池**: A 股主板 + 创业板 + 科创板（约 5000 只）

**筛选条件**:
1. 股息率 ≥3%（基于 TTM 数据）
2. **当日成交额** ≥5000 万元（流动性门槛；代码字段 `strategy/portfolio.py:63` 的 `min_daily_amount`。⛔ 原文误写为「自由流通市值」，市值与成交额经济含义不同，已按代码更正）
3. ST / 退市风险股**不剔除**（⛔ 原文「数据层自动过滤」为虚假方法论声明；`data/cleaner.py:317` 仅用 `isST` 推导 ±5% 涨跌停档，全仓无任何 ST 剔除逻辑，该能力**尚未实现**并已登记为待办）
4. 非停牌状态（实时过滤）

**排序方法**: 按股息率降序排序，取前 50 只作为候选池

**权重分配**: 按自由流通市值加权（市值越大权重越高）

### 2.2 调仓规则

**调仓频率**: 月度（每 20 个自然日调仓一次）

**持仓数量**: 3-8 只（默认 5 只，硬上限 10 只）

**单票下限**: ≥2 万元（整手化后）

**建仓逻辑**:
- 等权分配初始资金
- 按市值权重微调
- 整手化（100 股为单位）
- 停牌股自动剔除

**退出逻辑**:
- 月度调仓时自动更新持仓（卖出不在新信号里的股票）
- 择时空仓时全部清仓（见 2.3）

### 2.3 择时机制（MA200）

**指数基准**: 沪深 300 指数（000300）

**择时规则**:
- 沪深 300 收盘价 < MA200 → **空仓保护**（不持有任何股票）
- 沪深 300 收盘价 ≥ MA200 → 正常持仓

**冷启动期**: ≥200 个交易日（累积足够 MA200 数据）

**保护原理**: 熊市/震荡市指数趋势向下时，规避系统性风险

### 2.4 风险控制

**组合层风控**:
- 持仓集中度: ⛔ **未实现单票集中度上限**（原文「单票权重 ≤25%」为幽灵风控声明，已按代码更正）。实际权重来源：传入 `weights` 时按 `total_nav × w / Σw` 归一化（红利策略=流通市值权重），未传时等权 `total_nav / N`；3~8 只 ⇒ 单票 **12.5%~33.3%**（持有 3 只时自然 33.3%，**不会**被拦截）。已登记为待办。
- 流动性控制: 参与率 ≤5%（单笔买入 ≤ **当日成交额** × 5%，`strategy/portfolio.py:64`；⛔ 原文「日均成交额」口径有误；且仅**建仓端**生效，已持仓不加仓时不校验）
- 价格上限: 单价 **>300 元**的股票在建仓端自动过滤（`max_price=300.0`，`strategy/portfolio.py:151` 为严格大于 ⇒ 恰好 300 元**不**剔除；原文「≥300 元」与代码不符，已更正）

**执行层风控**:
- 停牌日不成交（引擎层自动跳过）
- 涨停板不买入 / 跌停板不卖出（撮合规则）
- T+1 约束（今日下单 → 明日开盘成交）

**偏差监控**（T402）:
- NAV 日偏差 ≤0.5%
- 月度收益偏差 ≤2%
- 月换手偏差 ≤10pp
- 超出容忍带立即告警

## 4. 预期收益与风险

### 4.1 收益来源

1. **股息收益**: 3%+ 股息率 × 持仓时长
2. **价值回归**: 高股息股长期跑赢（均值回归）
3. **低 Beta 效应**: 熊市抗跌，降低波动率

### 4.2 主要风险

**市场风险**:
- 系统性下跌：MA200 择时可部分规避，但无法完全消除
- 红利股整体低迷：若市场偏好成长股，红利股可能跑输大盘

**策略风险**:
- 择时失效：MA200 在震荡市可能频繁切换（回测中未发现，待模拟盘验证）
- 红利陷阱：高股息但业绩下滑的公司（通过 **5000 万当日成交额下限**过滤部分风险；⛔ 原文「市值下限」口径有误，已按代码更正）

**执行风险**:
- 滑点成本：月度调仓，实际成交价按价格模型设 5bps 基础滑点；⛔ 本轮回测产物 `fees_total.SLIPPAGE = 0`（未额外扣滑点），原文「偏离模型预期 1-2%」**无实测支撑**，属假设，禁止作为已核数字引用
- 停牌风险：持仓股票停牌时无法卖出（`backtest/matching.py::REJECT_SUSPENDED` 停牌不可下单，已纳入回测模拟）

**流动性风险**:
- 小市值红利股成交额不足：已通过 5000 万**当日成交额**下限 + 5% 参与率控制

### 4.3 风险等级评估

**⛔ 原「风险等级：中低（3/5）」评级已撤回** —— 实测 10 年 CAGR −3.20%、MDD 43.08%（**高于 35% 上限，`G-MDD-1` FAIL**）、胜率 28.21%，该风险收益特征**不支撑「中低」定级**；新评级待策略 v2 落地后按新材料重新评估。

**原「中低（3/5）」的支撑理由（逐条核后）**:
- 持仓股票为主板/大盘红利股，流动性较好
- MA200 择时提供熊市保护
- 月度调仓频率低，执行风险可控
- 无杠杆、无做空，最大损失 = 本金

## 5. 适用市场环境

**适合**:
- 震荡市 / 慢牛市（MA200 上方，红利股防御性强）
- 熊市初期（MA200 下穿后空仓保护）
- 低利率环境（高股息吸引力强）

**不适合**:
- 快速上涨的成长牛市（红利股跑输成长股）
- 极端流动性枯竭（如熔断机制触发，但已有压力测试验证）

## 6. 系统要求与质量门禁

**最高申报速率**: <1 笔/分钟（远低于高频认定标准 5 笔/秒）

**单日最高申报笔数**: 20 笔（调仓日 8 只卖出 + 8 只买入 + 缓冲）

**系统延迟**: 日终任务模式，无实时延迟要求（收盘后生成信号，次日开盘执行）
