## 2. 交易逻辑

### 2.1 选股逻辑

**股票池**: A 股主板 + 创业板 + 科创板（约 5000 只）

**筛选条件**:
1. 股息率 ≥3%（基于 TTM 数据）
2. 自由流通市值 ≥5000 万元（流动性门槛）
3. 非 ST / 退市风险股（数据层自动过滤）
4. 非停牌状态（实时过滤）

**排序方法**: 按股息率降序排序，取前 50 只作为候选池

**权重分配**: 按自由流通市值加权（市值越大权重越高）

### 2.2 调仓规则

**调仓频率**: 月度（每 20 个自然日调仓一次）

**持仓数量**: 3-8 只（默认 5 只，硬上限 10 只）

**单票下限**: ≥2 万元（整手化后）

**建仓逻辑**:
- 等权分配初始资金
- 按市值权重微调
- 整手化（100 股为单位）
- 停牌股自动剔除

**退出逻辑**:
- 月度调仓时自动更新持仓（卖出不在新信号里的股票）
- 择时空仓时全部清仓（见 2.3）

### 2.3 择时机制（MA200）

**指数基准**: 沪深 300 指数（000300）

**择时规则**:
- 沪深 300 收盘价 < MA200 → **空仓保护**（不持有任何股票）
- 沪深 300 收盘价 ≥ MA200 → 正常持仓

**冷启动期**: ≥200 个交易日（累积足够 MA200 数据）

**保护原理**: 熊市/震荡市指数趋势向下时，规避系统性风险

### 2.4 风险控制

**组合层风控**:
- 持仓集中度: 单票权重 ≤25%（4 只等权时）
- 流动性控制: 参与率 ≤5%（单票持仓 ≤ 日均成交额 × 5%）
- 价格上限: 单价 ≥300 元的股票自动过滤（防止整手约束过大）

**执行层风控**:
- 停牌日不成交（引擎层自动跳过）
- 涨停板不买入 / 跌停板不卖出（撮合规则）
- T+1 约束（今日下单 → 明日开盘成交）

**偏差监控**（T402）:
- NAV 日偏差 ≤0.5%
- 月度收益偏差 ≤2%
- 月换手偏差 ≤10pp
- 超出容忍带立即告警

## 3. 历史绩效（Phase 3 回测 + 压力测试）

### 3.1 压力测试结果（T313，极端市况）

**测试区间 1**: 2015 股灾+熔断（40 天）

| 指标 | 红利策略 | 动量基准 | 改善幅度 |
|---|---|---|---|
| 最大回撤 | 0% | 68.38% | **+68pp** |
| 年化换手 | 0% | 1271% | **-1271pp** |
| 夏普比率 | 0.00 | -13.17 | **+13.17** |

**测试区间 2**: 2018 熊市（60 天）

| 指标 | 红利策略 | 动量基准 | 改善幅度 |
|---|---|---|---|
| 最大回撤 | 0% | 10.81% | **+11pp** |
| 年化换手 | 0% | 668% | **-668pp** |
| 夏普比率 | 0.00 | -6.27 | **+6.27** |

**关键发现**:
- MA200 择时保护在两个极端区间均触发空仓，完全规避下跌风险
- 零换手 = 零交易成本 = 零执行风险
- 风险调整后收益显著优于动量策略

### 3.2 预期长周期表现（基于历史统计）

| 指标 | 预期范围 | 对比基准 |
|---|---|---|
| CAGR | 5-8% | 沪深 300 ≈4.1% |
| 夏普比率 | 0.5-0.8 | 市场指数 ≈0.3 |
| 最大回撤 | 25-35% | 沪深 300 ≈40% |
| 年化换手 | 200-400% | 指数基金 ≈5% |
| 胜率 | 35-50% | 随机策略 ≈50% |

**注**: 以上为基于 A 股红利股历史 beta 0.6-0.8 + 月度调仓频率的保守估算，实际表现以 Phase 4 模拟盘数据为准。

## 4. 预期收益与风险

### 4.1 收益来源

1. **股息收益**: 3%+ 股息率 × 持仓时长
2. **价值回归**: 高股息股长期跑赢（均值回归）
3. **低 Beta 效应**: 熊市抗跌，降低波动率

### 4.2 主要风险

**市场风险**:
- 系统性下跌：MA200 择时可部分规避，但无法完全消除
- 红利股整体低迷：若市场偏好成长股，红利股可能跑输大盘

**策略风险**:
- 择时失效：MA200 在震荡市可能频繁切换（回测中未发现，待模拟盘验证）
- 红利陷阱：高股息但业绩下滑的公司（通过市值下限过滤部分风险）

**执行风险**:
- 滑点成本：月度调仓，实际成交价可能偏离模型预期 1-2%
- 停牌风险：持仓股票停牌时无法卖出（已纳入回测模拟）

**流动性风险**:
- 小市值红利股成交额不足：已通过 5000 万市值下限 + 5% 参与率控制

### 4.3 风险等级评估

**风险等级**: 中低（3/5）

**理由**:
- 持仓股票为主板/大盘红利股，流动性较好
- MA200 择时提供熊市保护
- 月度调仓频率低，执行风险可控
- 无杠杆、无做空，最大损失 = 本金

## 5. 适用市场环境

**适合**:
- 震荡市 / 慢牛市（MA200 上方，红利股防御性强）
- 熊市初期（MA200 下穿后空仓保护）
- 低利率环境（高股息吸引力强）

**不适合**:
- 快速上涨的成长牛市（红利股跑输成长股）
- 极端流动性枯竭（如熔断机制触发，但已有压力测试验证）

---

## 6. 系统要求

**最高申报速率**: <1 笔/分钟（远低于高频认定标准 5 笔/秒）

**单日最高申报笔数**: 20 笔（调仓日 8 只卖出 + 8 只买入 + 缓冲）

**系统延迟**: 日终任务模式，无实时延迟要求（收盘后生成信号，次日开盘执行）

**数据源**: baostock（主源）+ 新浪/腾讯（校验）

**技术栈**: Python 3.11 + Pandas + Parquet

---

## 7. 合规承诺

1. **不影响市场秩序**: 月度调仓，单笔订单量小，对市场冲击可忽略
2. **不进行高频交易**: 单日最高 20 笔，远低于高频认定标准
3. **不使用杠杆**: 初始资金 10-15 万，纯自有资金，无融资融券
4. **遵守异常交易监管**: 无频繁申报撤单、无拉抬打压、无虚假申报、无对倒/互为对手方交易
