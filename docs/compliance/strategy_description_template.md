## 2. 交易逻辑

### 2.1 选股逻辑

**股票池**: A 股主板 + 创业板 + 科创板（约 5000 只）

**筛选条件**:
1. 股息率 ≥3%（基于 TTM 数据）
2. 自由流通市值 ≥5000 万元（流动性门槛）
3. 非 ST / 退市风险股（数据层自动过滤）
4. 非停牌状态（实时过滤）

**排序方法**: 按股息率降序排序，取前 50 只作为候选池

**权重分配**: 按自由流通市值加权（市值越大权重越高）

### 2.2 调仓规则

**调仓频率**: 月度（每 20 个自然日调仓一次）

**持仓数量**: 3-8 只（默认 5 只，硬上限 10 只）

**单票下限**: ≥2 万元（整手化后）

**建仓逻辑**:
- 等权分配初始资金
- 按市值权重微调
- 整手化（100 股为单位）
- 停牌股自动剔除

**退出逻辑**:
- 月度调仓时自动更新持仓（卖出不在新信号里的股票）
- 择时空仓时全部清仓（见 2.3）

### 2.3 择时机制（MA200）

**指数基准**: 沪深 300 指数（000300）

**择时规则**:
- 沪深 300 收盘价 < MA200 → **空仓保护**（不持有任何股票）
- 沪深 300 收盘价 ≥ MA200 → 正常持仓

**冷启动期**: ≥200 个交易日（累积足够 MA200 数据）

**保护原理**: 熊市/震荡市指数趋势向下时，规避系统性风险

### 2.4 风险控制

**组合层风控**:
- 持仓集中度: 单票权重 ≤25%（4 只等权时）
- 流动性控制: 参与率 ≤5%（单票持仓 ≤ 日均成交额 × 5%）
- 价格上限: 单价 ≥300 元的股票自动过滤（防止整手约束过大）

**执行层风控**:
- 停牌日不成交（引擎层自动跳过）
- 涨停板不买入 / 跌停板不卖出（撮合规则）
- T+1 约束（今日下单 → 明日开盘成交）

**偏差监控**（T402）:
- NAV 日偏差 ≤0.5%
- 月度收益偏差 ≤2%
- 月换手偏差 ≤10pp
- 超出容忍带立即告警

## 4. 预期收益与风险

### 4.1 收益来源

1. **股息收益**: 3%+ 股息率 × 持仓时长
2. **价值回归**: 高股息股长期跑赢（均值回归）
3. **低 Beta 效应**: 熊市抗跌，降低波动率

### 4.2 主要风险

**市场风险**:
- 系统性下跌：MA200 择时可部分规避，但无法完全消除
- 红利股整体低迷：若市场偏好成长股，红利股可能跑输大盘

**策略风险**:
- 择时失效：MA200 在震荡市可能频繁切换（回测中未发现，待模拟盘验证）
- 红利陷阱：高股息但业绩下滑的公司（通过市值下限过滤部分风险）

**执行风险**:
- 滑点成本：月度调仓，实际成交价可能偏离模型预期 1-2%
- 停牌风险：持仓股票停牌时无法卖出（已纳入回测模拟）

**流动性风险**:
- 小市值红利股成交额不足：已通过 5000 万市值下限 + 5% 参与率控制

### 4.3 风险等级评估

**风险等级**: 中低（3/5）

**理由**:
- 持仓股票为主板/大盘红利股，流动性较好
- MA200 择时提供熊市保护
- 月度调仓频率低，执行风险可控
- 无杠杆、无做空，最大损失 = 本金

## 5. 适用市场环境

**适合**:
- 震荡市 / 慢牛市（MA200 上方，红利股防御性强）
- 熊市初期（MA200 下穿后空仓保护）
- 低利率环境（高股息吸引力强）

**不适合**:
- 快速上涨的成长牛市（红利股跑输成长股）
- 极端流动性枯竭（如熔断机制触发，但已有压力测试验证）
