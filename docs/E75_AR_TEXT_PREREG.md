# E75 年报文本因子族预登记（冻结版）

> 冻结时间：2026-09-23（先于任何特征计算与筛选运行）。
> 数据源：`data/annual_reports_txt/`（Release `年到文本` 26 分卷，
> 73,480 份 txt，2000-2025，6,094 只含退市股——退市股抽查合格：
> 300104/600074/002018 均覆盖至退市年）。文件名锚：
> `{code}_{财年}_{简称}_{标题}_{披露日}.txt` ⇒ PIT 锚 = 披露日。
> 筛选窗 ≤2024-12-31（2025+ 只观察登记不筛）。

## 一、臂阵（5 臂 + 安慰剂，Bonferroni）

| 臂 | 特征定义 | 方向先验 |
|---|---|---|
| T1 | 文本长度：ln(字符数) 同年截面 z 分 | 负（披露负担/不透明） |
| T2 | 披露延迟：披露日 − 财年结束日（天数） | 负（拖延=坏消息） |
| T3 | YoY 文本相似度：MinHash-128 3-gram Jaccard（与本公司上年报） | 负（模板化=管理层敷衍） |
| T4 | 风险词密度：「风险」词频/千字 | 负（业务风险披露高） |
| T5 | 语调净正面：(pos−neg)/(pos+neg)，冻结词表（见附录） | 正 |
| T6 | 安慰剂：同批样本披露日随机错配 ±30td | ~0 |

T0=披露日，T+1 收盘入场（同 e49 口径），h∈{20,60,120}，
基线=同披露日截面均值收益；特征按"同年截面 z 分"后再做时序检验。
信号构型：事件型（每股票每年至多一条正式年报，更新/更正版本
取**首次披露**计 T0——更正重披本身也是事件，列入 T4 子臂登记）。

## 二、判定门（同构骨架）

- 判「强」：|t_cluster|≥2.6 + 方向合先验 + 年一致性≥60% + n≥300。
- 可成交性切片：判强者必跑剔除 T+1 涨停/停牌后残余效应；残余
  <50% 原效应 → 降「判强不晋级」。
- 覆盖期 <5 年或退市股缺失 → 如实降级标注（本语料已验退市股，
  预期达标）。
- T5 词表为冻结件（附录 A），命中密度 <0.5% 的臂如实标弱覆盖。

## 三、范围

- 判强正臂 → 年化事件增强轴（年报披露每年一次，稀疏性预期指向
  叠加因子而非独立策略——e41 教训：先算可成交切片再定形态）；
- 判强负臂 → veto/降权候选；
- T3 相似度判强 → "年报变脸/敷衍"独立事件轴候选登记。

## 四、已知局限

- 披露日取文件名解析（99.999% 命中，1 例失配记 unparseable）；
- 「更新/修订版」标题含「（更新后）/修订」字样——按首次披露计
  T0，修订重披单独登记不混臂；
- 文本编码混 GB18030/UTF-8（按 chardet 逐份探测，失败记异常不猜）；
- 语调词表为精简中文金融词表（附录），语义精度弱于专用词典，
  如实降级标注（先验强度 < 其他臂）。
