# E109 内部人交易流量轴 预注册（冻结于评估前）

## 数据
`data/cninfo_insider_all/`（cninfo webapi sysapi/p_stock2218_inc，董监高
及关联人持股变动全史 1993-2026，1.79M 行）。
字段：SECCODE / DECLAREDATE（公告日=PIT 锚点）/ F006N 带符号变动股数
（正=增，负=减）/ F008N 价格 / F010V 交易方式 / F002V 职务。
过滤：F010V ∈ {竞价交易, 二级市场买卖, 大宗交易}——仅真实市场
自主交易，剔除股权激励/分红送转/新股上市等非自主变动。
PIT：asof = DECLAREDATE + 1 交易日（公告日收盘后才可知，保守错后一天）。

## 信号（月度截面，近 90 日滚动聚合）
- `ins_net3m`：Σ F006N 净变动股数，log1p(|x|)×sign(x)
- `ins_buyn90`：F006N>0 笔数（增持次数）
- `ins_dir3m`：(增笔数 − 减笔数)/(增笔数+减笔数+1)（方向平衡 ∈(−1,1)）

## 假设
内部人净增持 = 知情交易者看多信号 → 未来 20 日收益更高
（informed-flow 假说；反向结论亦可登记，以方向稳定为准）。
BASE 已有 ev_insider_sell 二值事件标志；本轴评的是**流量维度**
（金额/笔数/方向平衡），不是事件有无。

## 判定门（沿用族标准）
- 月频 Spearman IC：|IC| ≥ 0.04 且 |t| ≥ 3 → 判强（晋级候选）
- |IC| < 0.02 或 |t| < 2 → 判弱
- 安慰剂：asof ±20 交易日错位重算，p ≥ 0.05 方可计真
- 区间：2016-01 ~ 2024-12（2025+ 永久 OOS 只观察登记）
