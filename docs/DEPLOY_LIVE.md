# DEPLOY_LIVE —— 实盘调仓操作手册（top20 / 10-15 万档）

## 0. 适用构型与期望

- 构型：e63 label150(h150) 分数 **top20 等权**，每个新分数期调仓一次
  （生产口径 reb60≈每 60 交易日；分数月产 ⇒ 实际月度跟随）。
- 回测参照（run 20260923-012520，含费含滑点）：**CAGR 25.72% / 换手 ~300%**
  ——这是**含成本上限**，实盘按 ~20%/年 期望管理（冲击/纪律损耗另扣）。
- 资金适配：10–15 万元；单票目标 ≈ capital/20 ≈ 5000–7500 元（100 股整手后
  会偏离，发射器自动迭代剔除不合规票并给候补）。

## 1. 每次调仓三步走

1. **产分数**（每月末后）：跑 `e63_score_2025.py` 得到最新
   `scores_label150_2025.parquet`（产出节奏：每月 1 期）。
2. **产清单**（下一个交易日前）：
   ```bash
   ./.venv/bin/python scripts/emit_live_basket.py \
       --scores experiments/lab/e63/scores_label150_2025.parquet \
       --topn 20 --capital 150000
   ```
   → 打印名单/股数/目标市值 + `experiments/live/basket_<日期>_top20.csv`。
   分数期距数据端 >45 天会**警告过期**——别用过期清单。
3. **执行**（次日开盘附近）：
   - **先卖后买**：清仓不在新名单里的持仓 → 再买新名单（T+1 约束，
     当日买入不可卖）。
   - 用市价单附近限价（滑点预算 ≤15bps/边）；涨跌停票挂不进就
     顺延到候补第一位。
   - 单票买不到整手下限（5000 元）就整票跳过，钱进候补。

## 2. 纪律（红线）

- ⛔ 不手改名单、不加减仓、不盘中追涨——alpha 全部在名单纪律里。
- ⛔ 停牌票复牌首日不抢（模型口径视为复牌风险日）。
- 月度分数若连续 3 期 IC 显著衰减（观察报表 <0.05）→ 停止执行，
  回评审档（E72 §3），不要"再扛一个月看看"。
- 现金余量（~5-10%）留在账户应付整手凑不齐与费用。

## 3. 已验证工具链

- `scripts/emit_live_basket.py`：选股/流动性/整手/min_pos 语义与
  `strategy.score_basket`+`portfolio.plan_positions` 同源；已实测
  （2026-09-22 数据端 19/20 成活，输出含候补 10 名）。
- 分数管线：dbasic 2025 补救 → `e63_build_2025.py` → `e63_score_2025.py`
  （产出即插入步骤 1 路径）。

## 4. 诚实边界

- 回测未含：冲击成本>15bps 部分、分红税精确科目、停牌无法卖出的实际
  冻结期；这些都在实盘真实发生，期望打八折理解。
- top20 窄篮波动大（2018 类年份仍可能年度亏损），不是月月稳赢；
  纪律性执行比择时更重要——历史上"择时开"臂反而 CAGR 8.81%。
- **ST 票是策略原生成分**：生产构型不剔除 ST（回测收益里本来就含
  ST 票贡献），发射器只在表格里标 ST 列不拦截——2026-09-22 首期清单
  19 只里 8 只是 ST。手动剔除=偏离回测口径（自行承担跟踪误差），
  接受=按策略语义执行；退市风险由等权分散 + 月度换血天然约束，
  但没有硬性保护，想清楚再下单。
