## 一、研究问题

现池 487 只并非高股息逻辑构建（与 ≥3% 全 A 高股息池重叠仅 9.7%，R7 实证），
且静态池含幸存者偏差（alive_universe ∩ 静态目录 ⇒ 2.45pp/年虚高）。
**C3 = 按 P1 规格在 PIT 全 A 宇宙上重选年度池**，测冠军构型（e8b 同参）
在重选池上的边际收益，对照锚 = isst-e8b（同 SHA 同数据、旧池）。

## 二、宇宙口径（预先固定）

- 基础宇宙：bar 宇宙 5473 = market-breadth-a/daily_bars（5220 在市）
  ∪ delisted_bars（253 退市）——**含退市票，去幸存者偏差**；
- PIT 成员资格：票于日 t 属宇宙 ⟺ 当日在市（alive_universe ∩ bar 存在），
  退市票在退市前正常参与（历史年份照常在册）；
- 重选节奏：**年度重选**——每自然年**首个交易日**快照定当年池
  （与 P1「每年末快照定次年池」PIT 等价：首日的可得信息即上年末信息，
  且自然覆盖 2015 年——2014 末无 daily_basic 数据，用 2015-01-05 首日
  快照；⛔ 不许用年末数据回选当年，那是前视）。年内不变；
- 行业标签：用 `data/pool_meta/stock_industry.parquet` **当前快照**（无 PIT
  数据源——tushare 不提供行业变迁史）。**登记简化**：历史年份用当前
  行业标签，偏差量级小但存在；缺失行业记录按「未知行业」单列计数
  （在市 0 缺失、退市侧 3 只无记录 + 333 空值行全 D 状态）。

## 五、判据（预先固定，收单时按此裁决）

- 主判据：CAGR 差 vs isst-e8b——
  - Δ ≥ +1.5pp 且 MDD 不劣化 >3pp ⇒ **池重选有效**，进 G-2/门禁流程；
  - Δ ∈ (−1.5pp, +1.5pp) ⇒ 边际不显著，登记归因后**弃**（不追加调参）；
  - Δ ≤ −1.5pp ⇒ 判负，P1 规格降级为研究记录；
- 守门判据：年化换手 ≤ 8（同 e11 口径）；持仓天数占比非病态
  （择时层行为不解释池效应）；池规模年均 ≥30 只（否则登记容量告警）；
- 交叉验证（只做一次、不迭代）：若主判据落在 ±0.5pp 模糊带，
  允许**唯一一次**分年一致性核查（10 年中 ≥6 年同向 ⇒ 判有效）。

## 七、诚实边界

- 行业标签为当前快照（无 PIT 源），历史行业映射有偏差；
- 支付率口径（税前/税后、分红年度归属）冻结时定，实现后不回改；
- P1 阈值来自外部报告，本仓复核只验「可执行性/量级」不验「最优性」；
- 池重选不解决阈值稳健性（G-2）问题——两线独立验收（C3 修池、
  G-2 修参数）；
- 年度重选+年内不变是 P1 规格；滚动/季频重选是另一实验，不在本登记。

### A.2 阈值复核结论（逐条）

- **R1 dv≥3**：首日截面 52-492/年。2015-2017 稀疏（52-69）——早期
  高股息票本身少，非数据缺陷（dv_rows 覆盖 2342-5329 行/日，
  stock_basic 覆盖 5473 全宇宙零缺失）。
- **R2-R4 质量（ROE>0 + 净利同比>0 + 负债<80%）**：合计剔除
  R1 的 ~40-55%（2016 最狠 52→23）。三板斧叠加有效压缩。
- **R5 支付率 ∈(0,1)**（口径=Σcash_div 税前/同财年 eps，
  ann_date≤快照 PIT 严）：达 R5 的 1582 只中 **通过 1404（88.7%）**、
  ≥1 剔 154（9.7%，分红超收益=不可持续，剔除合理）、无分红剔 23、
  eps≤0 剔 1。上下界均有实际约束力，不过紧不过松。
- **R6 近一年跌>50% 剔**：修复 base_partition_day 后真实生效——
  2016 剔 2（2015 股灾重伤票）、2019 剔 49（2018 熊市重伤票）。
  基期=快照约一年前最近分片（±10 日），2015 无基期（分片始于
  2015）该年不施加，如实登记。
- **R7 行业 ≤20%**：**十年均未触发**（终池=R6 后数）——110 个行业
  标签下最大行业占比未超 20%，规则存在但无约束。如实登记：
  R7 在本数据上等价于 no-op。
- **容量告警（如实登记不放宽）**：2016 终池 **21 只 <30**、
  2015/2017/2018 为 37/37/49（<50）——早年池偏小，持仓 3-8 只
  时集中度风险存在（单票占比高）。非判据失败，但结论解读时须注明
  早年样本稀薄。终池年均 130.2 ≥30 守门成立。
- **池-旧池重叠**：各年 ~7-19%，与 R7 实证（9.7%）一致——新池与
  487 池基本不相交，测的是真·换池效应。
