## 3. 如实呈现：策略在这两个区间的行为病理

1. **2015-crash 段**：动量信号在跳水段追高买入（9 天上升段的信号），买入即接跌；到中段触发 MomentumStrategy 的「跌出前 N + 时间退出（25 日）」逻辑强制卖出时已经巨亏；熔断期想卖也卖不出（限卖）。
   - 实测=理论：动量信号在趋势中断 + 强制流动性干涸市中**必然**是右侧追涨、左侧抄底双输。**指标如实体现。**

2. **2018-bear 段**：连续性阴跌 + 反弹节奏抓不住；动量信号永远在反弹后一天入场、在阴跌中被套，到 25 日时间上限强制退出锁定亏损；期间胜率 0%——熊市里做多动量没有 alpha。**指标如实呈现（−10.8%、MDD 10.8%、Sharpe −6.3 全负）。**

3. **同一策略在 2015-crash 中比在 2018-bear 中**承受的回撤 ≈ 68% vs 11%，**如实的回答了「这个策略遇上股灾会怎样」——不是策略烂，是它根本不该在那种市场阶段运行**。

## 4. 结论 / Phase 3 以此进入 T305 的判断

- ✅ **策略没有粉饰的空间**：两段指标均为负且幅度如实反映在 PerformanceReport 里。
- ✅ **工程链路健康**：NAV/交易/费用/胜率/回撤全程可复算（⛔ 本报告没有手工数字）。
- ⛔ **该候选策略当前形态的熔断期 / 持续熊市表现低于可接受水位**——T303 参数扫描也没把它救活的机会（它会只加剧/缩短痛苦）。
- **工程判断（诚实版）**：Phase 3 暂不推进 v1 动量候选策略上模拟盘；T305 评审前应**至少评估两类替代或修正**：
  - 引入趋势过滤（只在大盘 MA200 上方开仓）；
  - 或引入低 beta / 红利价值风格（与本系统持仓规模匹配）；
  两个方向都属「换策略」（T302 迭代）而非 T304 修补。
- ⛔ **如实呈现** ：本报告不输出「建议启动 Phase 4」的结论，那属 T305+G4 的用户决策。
