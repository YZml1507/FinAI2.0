# 工程 IP 资产清单（IP_ASSETS_MANIFEST）

> E 路线第一步产物（2026-09-21）。每条资产：卖点一句话 + 实测证据指针。
> 用途：对外包装/许可评估的底账；「实测」= 本仓跑过的证据，非宣传语。

## A1 — fail-closed 门禁审计框架（旗舰）

- **是什么**：29 道自动门禁（7 域 D-L-E-A-S-G），对一次回测产出做全链审计：
  数据卫生（停牌脏行/复权口径/覆盖）、幸存者偏差实测量化、引擎正确性
  （五必挂）、账务守恒（逐日现金流/费用逐项/税档）、科学纪律（多重比较/
  预登记）、治理（密钥扫描/幻影引用）、可复现指纹。
- **实测证据**：`python -m scripts.gates.gate_master_audit --scheduled` 每日
  定时 29 门 = 28P/0F/1S/0I（2026-09-21）；e20 曾自我拦下冠军策略
  （能产出否定答案的风控本质）；`must_fail_probe` 故意造坏验证门禁会红。
- **卖点**：市面回测工具回答「赚多少」，这套回答「这数字能不能信」。

## A2 — 事件驱动回测引擎（A股规则全真）

- **是什么**：七态订单状态机 + Journal/BookView 双账本 + 八撮合规则
  fail-closed（停牌/涨停/跌停/T+1/整手/零股/资金/次一开盘）+ 六科目精确
  费用（Decimal ROUND_HALF_UP）+ 红利差别化税 FIFO 三档 + 送转扩仓。
- **实测证据**：`tests/` 1229 项全绿；07 号黄金算例 10 万往返 112.82 元
  逐项口径可核；T313 压力双场景报告。
- **卖点**：散户口径全建模（¥5 保底/税档/整手）——多数开源引擎不建这层。

## A3 — PIT 数据平面与采集器族

- **是什么**：财报时点连接（financial_pit_alla）、含退市票全 A 序列
  （daily_basic_alla 2431 日截面）、幂等断点采集器 ×6（两融/龙虎榜/
  大宗/情绪/户数/内部人/行业）、原子落盘 + manifest。
- **实测证据**：Release `data-20260920b` 分发链路跑通（MD5 校验）；
  内部人 11.4 万行/户数 17.5 万行实测落盘零失败页。
- **卖点**：PIT 正确性是小私募最常偷工的地方——这套直接可用。
- **合规边界**：上游数据协议（baostock/akshare/东财/巨潮）转售权待逐源
  审查——**只能许可加工方法与管道代码，不能转售原始数据**。

  收单回填七段式）+ 范畴评估模板 + 研究轮次索引。
