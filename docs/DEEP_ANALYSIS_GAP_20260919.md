## 二、机构在做什么（拆开看它们的收益来源）

**华泰行业中性组合**（2016-2026 实测 11.7%/MDD 23.1%/Sharpe 0.69）的结构： <!-- gate-doc-ignore:外部调研引用或历史快照实测值，非本项目当前基线声明 -->
- 池子：全A → 3年连续分红 + 5年股息率均值>中位 + **变异系数<中位**（稳定性！）
  + 预测股息率≥2.5% + ROA 分位加权
- **行业中性**：每申万一级行业取前 2 名等权——行业分散是结构性保证，
  不是 cap 上限（我们的 R7 cap20% 只是封顶，十年没触发过=形同虚设）
- **满仓常持、年频调仓**——不承担择时风险，吃满因子溢价
- 收益分解逻辑：股息再投资 + 低估值暴露 + 低波暴露 + 「填权」效应，
  超额 7.2pp 全部来自**选股纪律而非择时**

**华泰FCF稳定组合**（19.8%/Sharpe 0.96）：FCF TTM + 剔 capex/OCF>0.4 + <!-- gate-doc-ignore:外部调研引用或历史快照实测值，非本项目当前基线声明 -->
FCF 加权 100 票——收益引擎同样是「持续满仓持有一篮子高质量现金流公司」。

**共同点**：收益引擎 = **满仓 + 分散 + 质量/稳定性筛选**；择时在它们的体系里
是可选的增强层（华泰三指标择时再叠加 +9.9pp），不是收益来源本身。 <!-- gate-doc-ignore:外部调研引用或历史快照实测值，非本项目当前基线声明 -->

## 三、根因诊断：架构倒置

**我们现在的架构**：择时（breadth 三档）= 收益引擎 → 在 attack 窗口内
用集中持仓（≤5票）捕捉个股 alpha → 空仓吃 GC001。

**问题链条**：
1. 择时精度有上界——宽度信号牛熊转换快、震荡市双向挨打（2020 失血 −10.8%） <!-- gate-doc-ignore:外部调研引用或历史快照实测值，非本项目当前基线声明 -->
2. attack 确认要 breadth>0.35+连续——**进场天然滞后**，错过反弹前段
3. mid 带/低仓位日是纯机会成本（权益溢价漏接）
4. 集中持仓放大特异性波动但不加期望收益（选股层疑似负贡献：
   veto 配对 −1.02pp；e15 placebo 待裁决）
5. 结果：beta≈0、胜率<50%、靠防御省出来的回撤换掉了同等量级的上行

**机构的架构**：因子组合（满仓、分散、稳定筛选）= 收益引擎 → 择时仅作
尾端对冲/风格切换 → 不追求逃顶抄底，追求**持续暴露**。

**一句话**：我们在「什么时候持」上精益求精（且已证到瓶颈），
机构在「持什么+一直持」上精益求精。收益上限差 = 权益风险溢价的漏接率。

## 五、破解路径（按裁决顺序）

**P-0 e15-etfattack placebo（进行中，决定性分叉）**：
同择时下持 510880 替代选股栈。若 placebo ≥ 选股栈 ⇒ **选股层整体负贡献**，
个股层应整体废弃；若选股栈仍胜 ⇒ 保留个股但改分散度。

**P-1 架构倒置实验（本报告核心提案，须预登记）**：
把「择时引擎+偶尔持仓」倒置为「满仓因子核心+择时对冲」——
- 核心层：C3 池（年度重选，年均 130 只）→ 加低波翼（过去一年波动率升序截断）
  + 分红稳定性（3年连续+变异系数）→ 行业内分散取前 60-80 只等权/股息率加权，
  **全程满仓**；
- 对冲层：breadth 信号降级为仓位系数（defense 档减仓而非清仓，
  如 ×0.3~0.5 而非 0），治尾部不追逃顶；
- 现金层 GC001 保留。
- 预期收益桥：满仓因子底仓对标华泰 11.7%（其 MDD 23.1% 无择时保护）， <!-- gate-doc-ignore:外部调研引用或历史快照实测值，非本项目当前基线声明 -->
  叠加我们的 demote/宽度防御砍尾 → 目标 CAGR≥10% 且 MDD<20%——
  **这正是 e 系列一直在逼近但从架构上达不到的组合**。

**P-2 若 D1 归因显示股息率无残差 alpha**：池子定义从「股息率≥3」改为
「质量+低波+稳定分红复合因子」直接选股（股息率退居验证指标）。

**P-3 宏观择时增强**（数据可得性验证后）：期限利差+银行间量叠加现有宽度
（华泰实测超额 9.9pp/年）。 <!-- gate-doc-ignore:外部调研引用或历史快照实测值，非本项目当前基线声明 -->

## 六、诚实边界

- 华泰 11.7% 为研报样本内数字，含其选股规则的全部事后选择偏差； <!-- gate-doc-ignore:外部调研引用或历史快照实测值，非本项目当前基线声明 -->
  复现到我们数据面上可能打折（先跑 D1 归因再定主方向）。
- 「满仓+低波分散」在 2015/2018 型系统性熊市里 MDD 会显著大于
  现在的 17.4%（满仓红利指数当年 -46%）——倒置架构**必须保留择时对冲层**，
  只是把择时从「收益引擎」降级为「尾部保护」，这是与纯满仓的关键区别，
  也是我们现有组件（demote/GC001）的复用点。
- 流动性：C3 池含小票（2016 年仅 21 只告警），满仓分散化对容量有要求，
  需保留 min_daily_amount 与参与率 5% 约束（现有机制沿用）。

## 七、结论

我们差不在参数、不在池子、不在数据——**差在架构**：把择时当收益引擎
（精度有上界+天然滞后+双向挨打），把持仓当附属品（集中、间断、低敞口）。
机构的收益引擎是「满仓分散持有质量/低波/稳定分红组合」，择时只是对冲。

破解不是再调一个参数，而是 P-1 倒置实验：**满仓因子核心（低波+稳定+
分散）+ 择时降级为尾部对冲**。所有要素本仓已有现成组件
（C3 池/年度provider/breadth信号/GC001/liquidity cap），是重组而非新建。
下一步：等 e15 placebo 裁决选股层 → 预登记 P-1。
