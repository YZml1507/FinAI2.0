## 一、信号族（全部 PIT by PUBLISH_DATE）

| 信号 | 构造 | 假设 |
|---|---|---|
| rev_breadth60 | 60 日内对同机构同预测年 EPS 前值的上修数−下修数（/有前值报告数） | 上修宽度>0 → 基本面动量，Fwd 正 |
| rev_dir60 | 同口径净值方向均值（±1） | 同上，方向版 |
| dispersion | 截面内各机构 EPS2（次年）预测 std/mean | 分歧大→不确定性，Fwd 负 |
| cov_chg60 | 60 日新覆盖机构数变化 | 关注度上行 → 正 |
| rating_dir | 评级文字上调/下调事件流（最近一条方向） | 事件日精度，Fwd 同向 |
| eps_slope | (EPS3−EPS2)/|EPS2| 期限斜率（一致截面内） | 远端上修结构 → 正 |

## 二、判定门（沿用体系）

- 月频 IC ≥0.04 且 t≥3 → 判强；t<2 或 IC<0.02 → 判弱；
- 事件族（rev_dir60/rating_dir）必跑 ±20 日安慰剂 p<0.05；
- 覆盖 ≥60% 交易股（预警：窗口内无预测的小票天然无信号，
  覆盖偏差本身登记为局限）；
- 入 e83 式边际扫描门：IC_train ≥ 当时冠军集+0.008 才进引擎验证；
  引擎门 ΔCAGR ≥+1pp 且 ΔMDD ≤+2pp。
