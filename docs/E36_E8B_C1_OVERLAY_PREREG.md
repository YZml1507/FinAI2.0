# e36 预登记（草案，未冻结）：e8b 冠军构型 × C1 合成信号上游叠加 A/B

> 创建：2026-09-21 ｜ 状态：**草案 —— 冻结前置=叠加管线落地且基线臂
> 逐位复现锚点指纹**（与 e33 同纪律：先证实技术口径再冻结再跑）。
> 定位：范畴评估 `docs/E33_CATEGORY_ASSESSMENT.md` 方案 B 的执行件——
> 不是新策略立项，是冠军构型 isst-e8b 的「参数外增强」影子 A/B。

## 一、动机与证据

- e33-C1（S5 户数分位 + M5 融券环比 + F6 ROE 稳定 + I3 行业残差反转
  等权 z）是项目最强影子信号：t=4.46、年一致性 1.00、LOO 消融全强。
- 但其原生形态（全 A 五分位多头端 ~730 股篮宽）与散户 3-8 只持仓
  结构不匹配，净边际 ~1.7%/年贴滑点带上缘——不立项独立引擎。
- 未裁决的剩余问题：C1 作**上游排序/加权信号源**叠到既有冠军构型
  的选股层，是否在真引擎真费率下产生净增量？本实验回答该问题。
- 证据边界：e33 超额是全 A 五分位均值口径，**不承诺**迁移到 e8b
  487 池的 5 只集中持仓——这正是本 A/B 要实证的。

## 二、宇宙与数据

- 回测宇宙：isst-e8b 锚点构型逐位不动——487 红利池
  （universe_provider 冻结件）、宽度择时 v2、MA200、拥挤熔断、
  质量否决/排雷层、费率全真（佣金+印花+过户+红利税+滑点）。
- 合成信号：C1 日度 z 序列旁车 parquet 一次性预计算——
  `experiments/lab/e36/c1_scores_daily.parquet`（date × symbol → z），
  由 e33 同源 builder 逐日 PIT 产出（gdhs ann_date ≤T / margin ≤T /
  pit 报表披露 ≤T / 行业快照 ≤T），缺口股记缺失不入股。
- 注入点（已查证）：`strategy/candidates.py::_select_stocks` 产
  Signal 列表 → `scores` 字典 → `plan_positions(weights=scores)`；
  叠加经新配置位 `cfg.composite_overlay`（provider 注入
  {day → {sym: z}}），不改引擎、不改既有默认路径（默认 None=逐位
  复现锚点）。

## 三、假设与臂（双臂，共用基线）

- **A 基线**：现 e8b 锚点构型零改动重跑。复现判据 = **metrics/NAV/
  成交序列与锚点 `20260921-093948` 逐位一致**——参数/数据/日历/宇宙
  hash 应一致；code_hash 必然不同（内容寻址=git HEAD，任何提交都变），
  行为等价由输出逐位一致来证明；params_hash 因新增 overlay 配置字段
  会变化（schema 扩展，如实登记，不视为口径漂移）。复现失败则本实验
  技术无效，先修口径再谈。
- **B_tilt 权重倾斜臂**：候选集不变，调仓权重
  w_i ∝ market_cap_score_i × max(0.10, 1 + 0.30·clip(z_i, −2, 2))；
  λ=0.30 与 clip ±2 预登记定死（不做 λ 扫描——防自由度泄漏）。
- **C_filter 准入过滤臂**：候选排序不变，剔除 z_i < 0 的候选
  （合成负分不买），其余链路不动；若过滤后候选 < portfolio 下限
  则该期按原序补足到 min_positions（防止池坍缩，如实登记触发数）。
- 成功判据（双门同过才算「增强」）：
  **① ΔCAGR(臂−A) ≥ +0.5pp/年（引擎内全成本净口径）；
  ② ΔMDD ≥ −1pp（回撤恶化不超过 1 个百分点）。**
- 次级登记（不成闸）：逐年胜率 ≥60% 期望、换手增量、分年度
  NAV 差曲线、daily ρ(臂,A)——用于形态归因，不用于放行。

## 四、统计量与闸门

- 引擎级 A/B = 单条 10 年路径配对比较；诚实声明：**N=1 轨迹**，
  不存在常规 t 检验的样本量语义——判据故用硬阈值 + 逐年配对
  胜率 + 分年 NAV 差单调性三条定形态，不用影子 t。
- 全成本：引擎实算（含红利税 FIFO 档位、滑点、整手）。
- 判负出口：两臂均不达 ΔCAGR+0.5pp ⇒ C1 作 e8b 上游的路线判负，
  C1 退回候选库（保留「全 A 五分位影子已证」的既有地位），
  本线收单，不再设计第三臂。
- 判强出口：任一臂双门过 ⇒ 进 PROMOTION_CHECKLIST 评估（成为
  e8b-v2 候选构型，仍须走既有晋升闸全套，非直接部署）。

## 五、分支决策与明示不重试

- 本实验仅评「叠加有效性」，**不**评审 e8b 本体优劣；
- 不允许为凑 0.5pp 调整 λ/clip/过滤阈——冻结后参数不可动，
  任一臂不达标即如实收单；
- 基线臂复现失败 = 实验技术中止，修后重排，不算负证；
- 禁止用 2025+ OOS 段做任何参数/构型调整（该段仅作登记观察）。
