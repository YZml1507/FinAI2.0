## 二、宇宙与数据（冻结）

| 项 | 口径 |
|---|---|
| 宇宙 | 当日两融标的 ∩ 全 A 有效（= margin_detail 当日出现的 ts_code ∩ 基础有效），**仅两融资格池内结论不外推全 A**（资格本身偏好大盘/流动性，如实登记该条件化） |
| 窗口 | 2015-01-05 → 2024-12-31（同 e23/e25） |
| 信号日 | 每月最后交易日 T；**融资字段统一滞后 1 交易日**（用 ≤T−1 的 margin 截面） |
| 前瞻收益 | T+1 close → T+21 close（20 交易日，非重叠，同 e23/e25） |
| 数据源 | `data/margin_detail/{YYYYMMDD}.parquet`（scripts/collect_margin_detail.py 采集，两市归一化）；`daily_basic_alla` 提供 close/circ_mv/free_share；剔除/跳空/上市 <120 日口径同 e23 |
| 字段 | fin_balance 融资余额(元)、fin_buy 融资买入额(元)、short_qty 融券余量(股)；流通市值=circ_mv（元）、流通股本=free_share |

## 三、假设（6 个，方向先验冻结，⛔ 不搜参）

| # | 假设 | 构造（T 时点，全部用 ≤T−1 的 margin 日序列） | 方向 |
|---|---|---|---|
| M1 | 融资余额 20 日环比 | bal(≤T−1)/bal(≤T−1 前 20 交易日) − 1；两期均须存在 | 多低 |
| M2 | 杠杆买入强度 | mean( fin_buy / circ_mv )（≤T−1 起近 20 交易日，≥10 日有效否则 NaN） | 多低 |
| M3 | 融资余额占比 | fin_balance / circ_mv（≤T−1 最新截面） | 多低 |
| M4 | 融资余额 5 日环比 | 同 M1 窗改 5 日 | 多低 |
| M5 | 融券余量变化 | short_qty(≤T−1)/short_qty(前 20 日) − 1；分母 0 → NaN | 多低 |
| M6 | 融资买入/余额周转 | mean( fin_buy / fin_balance )（近 20 日，≥10 日有效） | 多低 |

方向依据：融资活跃度低 = 杠杆资金未拥挤流入 → 先验为正（反向指标）。

## 四、统计量与闸门（冻结，同 e25 骨架）

- 五分位组合（n//5 两端各一组）；主指标 = Q_top−Q_bottom 非重叠月度
  fwd20 价差；副指标 = Q_top−全宇宙等权；披露 RankIC。
- **G1** t ≥ 2.0；**G2** 年度符号一致 ≥60% 且两半窗同号为正；
  **G3** Q_top 月换手×0.30% ≤ 月均价差 50%。
- **G4（按两融宇宙修正口径）**：信号有定义月（n≥5）中，
  n < max(300, 当日两融标的数×50%) 的月份占比 ≤30%。
  （覆盖性阈值随资格池规模自适应；绝对下限 300 保五分位篮 ≥60 只。）
- **多重比较**：6 假设一次性登记，Bonferroni「强」阈 **t≥2.6**
  （同 e23 六假设口径）；「弱」= 2.0≤t<2.6 且 G2/G3/G4 全过；
  有效月 M<60 → INCONCLUSIVE。
- **合成臂**：≥2 个弱及以上 → z-score 等权合成 1 臂（披露，不计入基数）。

## 五、分支决策（冻结）

- 任一「强」→ 评估是否进引擎：两融宇宙非红利池，成立则属**新策略族**，
  走范畴变更评估会（宇宙/成本/容量/两融标的资格风险），⛔ 不直接进引擎
- 无「强」有「弱」→ 合成臂一次性测试（§四）
- 全判负 → 如实关闭；两融族关闭后行为资金族仅剩股东人数/内部人增减持
  候选（届时另行立项，⛔ 不自动续）

**明示不重试**：e23/e25 已判负族任何变体；融资信号滞后口径放松
（T 日数据 T+1 才可见，提前用=前视）；融券单因子扩窗搜参；
2025+ 数据任何形式使用；事后调阈值。

### 如实登记

- **已知口径特性（承 e23/e25）**：上市 <120 交易日剔除的实现对**面板窗口
  起点前已上市**的票也从窗口首日重新计数 → 2015-01~06 全员视为
  「未满 120 日」→ 前 6 个月信号未定义（n=0）。等价于窗口首 ~120 日
  暖机期；对全部假设一致、无前视、不改变方向——保守偏严而非宽松。
  三屏共用该实现，跨研究可比；本次不改冻结口径。
- M5 信号分布尾部极端（20 日环比 p99=+2169%，p1=−100%）——冻结口径
  无缩尾；是否为离群值驱动属评估会核查事项。
- M5 换手率 81.3%/月偏高：G3 以 0.244% vs 上限 0.246% 微弱通过；
  净边际 ≈ +0.25%/月，落在滑点模型误差带内——评估会重点。
- 融券机制沿革：2015-08 股灾后融券实质受限、2019 科创板重启转融通——
  M5 两个半窗同号为正（+0.40%/+0.58%），但该信号的横截面含义在
  两个 regime 可能不同质，如实披露。
- n_min=0 月份集中于暖机期；两融标的数月度中位 ~1600 只，
  截面规模始终满足 G4 自适应阈。
