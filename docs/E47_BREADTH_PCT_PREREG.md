# E47 宽度择时非参数化改造预登记（冻结版）

> 冻结时间：2026-09-21（先于任何 percentile 模式回测运行）。
> 承接 e44 收单元教训：「阈值悬崖病不在台阶形状」——e44 暴露
> 配平斜坡全负，证明 hard 台阶是功能性形态；病灶在**绝对阈值的
> 水平参数化**（0.25/0.35 是全期常数，市场宽度分布 regime 漂移
> 时阈值相对位置漂移，G-2 ±10% 扰动即撞崖）。
> 本族假设：把绝对阈值换成滚动分位数（non-parametric within
> regime），悬崖应消失或变缓。

## 一、改造定义（冻结）

`breadth_pct_window` 模式：日度宽度 b_t 不再直接比绝对阈值，
先映射为自身滚动分位：
  pct_t = rank(b_t, trailing W 窗口含当日) ∈ [0,1]  （W=250td）
  cap_t = defense 若 pct_t < q_d；attack 若 pct_t ≥ q_a；
          中线 mid_cap 线性过渡（同 hard 台阶语义，作用在 pct 域）
冻结网格（**pre-run 修订**）：W∈{200,250,300}、q_d∈{0.20,0.25,0.27}、
q_a∈{0.30,0.35,0.40,0.45,0.50,0.70,0.75,0.80}。
修订理由：首轮标定发现恒等式 P(pct≥q_a)≈1−q_a——原 q_a≥0.70
网格的攻击暴露上限 ~30%，永远达不到 hard 的 60.1%（配平不可行）；
q_a 域须下探到 ~0.40 才能配平攻击暴露、q_d 补 0.27 档贴近
P(defense)=0.265。修订在任何 --run 之前完成并登记。
校准=≤2020 训练段内选使 E[cap_t] 最接近 hard 基线平均暴露
（同 e44 暴露配平纪律：不借改造偷暴露）的 (W,q_d,q_a) 单点，
冻结后跑全窗——**不做网格择优后取优**。

## 二、臂阵（5 臂，同 e37promo 电池骨架）

| 臂 | 构型 |
|---|---|
| verify-hard | 冠军 hard 构型逐位复现锚（对照门） |
| pct-cal | 校准单点 percentile 模式（主评估臂） |
| g1-holdout | pct-cal 2021-24 留出半窗 |
| g2-pm10 | pct-cal 的 W±20%、q±0.05 局部扰动×2 |
| g3-fee2 | pct-cal 费率×2 |

判定：
- pct-cal 判「有效」：ΔCAGR ∈ [−0.3pp, +∞) 且 ΔMDD ≤ +1pp
  vs verify-hard（不劣化为门槛，增量不必正——择时层只需不拖）；
- **主假设检验**：G-2 扰动下 |ΔCAGR| 与 |ΔMDD| 应显著小于
  hard 域的悬崖（hard 参考点：a315 ΔMDD +4.02pp）。若 pct 域
  扰动仍出现同级悬崖 → 主假设证伪，悬崖病归因改记
  「台阶形态×市场结构共振」而非参数化方式。
- G-1 留出翻负 → pct 模式不晋级（同 e37promo 条款）。

## 三、实现与纪律

- `candidates.py` 加 `breadth_pct_window: Optional[int]`——
  非空时内部对宽度序列做 rolling-rank 映射（PIT：trailing
  窗口含当日，无前视），阈值域换 pct。
- 数据=既有 breadth20_daily.parquet，不引新数据轴。
- 校准只用 ≤2020 段；2025+ 永久 OOS 只登记不据此调参。
- 若判负：宽度择时参数化问题整体关闭，转「择时层价值评估」
  （择时 on/off 对照）为唯一剩余路径。

## 三补、标定结果（pre-run）

标定单点：**W=200, q_d=0.27, q_a=0.40**（score=0.021；e_att
0.5985 vs hard 0.6012，p_def 0.2469 vs 0.2654）——双配平达标。
pct 文件=experiments/lab/e47/breadth_pct_w200.parquet。
结构发现登记：pct 域 q_a≈0.40 才等价 hard 0.35 阈值——绝对阈值
携带的「60% 时间满仓」水平信息在分位域表现为低分位门槛，
两者语义无优劣但暴露了 hard 阈值的真实载荷在**水平**而非
截面形状——本电池即在检验水平载荷是否悬崖来源。

## 四、已知局限

- 滚动 rank 使 cap_t 隐含「宽度必回复自身分布」——长期趋势性
  宽度扩张期 pct 域会系统性低估绝对风险（2024 红利风格极端化
  段可能暴露），如实登记。
- W 本身仍是参数——只是把悬崖从「水平」搬到「窗长」；G-2
  含 W±20% 即为检验此点。
