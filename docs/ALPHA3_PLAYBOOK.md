## 二、操作铁律（违反=返工）

1. **零前视**：财务/预告一律 `pub_date` 对齐；价格序列 RAW 不复权。
2. **fail-closed**：开关开了数据不在就 raise，⛔ 不许静默降级。
3. **幂等原子写**：数据产物先写临时文件再 rename。
4. **防幸存者偏差**：股票池用当日 universe_provider。
5. **防过拟合**：任何新参数做 ±20% 扰动悬崖检验 + 跨周期分段验证，
   悬崖敏感即弃。
6. **测试纪律**：全量 pytest 必须全绿；`TEST_BASELINE_PASSED` 与实际
   收集数同步；文档新增实测数字若是历史快照须加 `gate-doc-ignore` 行内
   豁免（理由含「历史快照」）。
7. **改完 commit**：每个原子任务完成即 commit + 更新 TASK_TRACKER
   时间戳；FINDING 台账行数只增不减。
8. **实验命名**：`e<N>-<短名>`，结果写 `experiments/lab/<name>/`，
   leaderboard.jsonl 是事实源。
9. **唯一须停手请示**：删除数据 / 仓库级破坏性操作。其余决策自行拍板
   并写明理由。
10. **禁止空等后台任务**：采集/回测等长任务挂后台期间，必须并行推进
    可并行工作（验证、测试、文档、干跑预演、下一棒准备）；仅当确实
    无任何可并行事项时才允许等待，且等待前须向用户说明「已无并行
    事项」。轮询间隔应长（≥5min），不许高频空转。
11. **飞书汇报纪律**（通道：`sudo -n hermes send --to
    "feishu:oc_003282df1130aecae1195abe51d8aec4" "【devin】内容"`）：
    - **必报（即时）**：实验收单（名称+CAGR/MDD/换手+对照锚+裁决）、
      门禁/冻结/物化里程碑、异常阻塞（采集 fails>0、pytest 红、数据
      完整性告警）、方向切换（关闭旧方向+选定新方向）。
    - **心跳**：连续工作每满 2h 无必报事件时，发一条 ≤100 字进度
      （当前任务+下一步+有无阻塞），不许无声超过 2h。
    - **不报**：例行 commit、单次工具调用、中间思考——禁止刷屏。
    - **面向用户的回复**：凡回复群里消息，正文必须经此通道发出
      （TUI 输出用户看不到）。

## 三、标准实验流程（照此执行，不跳步）

```
1. 改代码 → 2. pytest 全绿 → 3. commit
4. run_experiment.py --name e<N>-xxx --set ...（后台，日志 _logs/）
5. 等 experiment.json → 6. 对照基线登记 TASK_TRACKER → 7. commit
```

- 消融原则：一次只动一个变量，命名体现实验变量。
- 对比基准恒为进攻基线 `bd25a35m00i1`（5.82%/31.28%），不是 MA200 基线。
- 任何「感觉会更好」的改动都必须落成实验编号，不许口头裁决。

## 五、性能受限模式（后继弱模型专用）

额度降级后按以下优先级收缩工作面，**宁可慢不可错**：

1. 只做已列入决策树的下一步，不主动开新方向；
2. 每个动作更小步：改一处→测一处→commit；
3. 不确定时优先保守分支（block_only 优于 exit，不加参数优于加参数）；
4. 遇到与台账冲突的「新想法」，先把理由写进 TASK_TRACKER 决策记录
   再动手——写不出理由就不做。
