## 2. Phase A：G4 策略层修复

### A-1 建不满仓根因拆解（P0，先于一切）

- **事实**：54.7% 日子零持仓，不是『满仓选错票』而是『长期建不满仓』。
- **任务**：给五道过滤器（存活股票池、股息率 ≥3%、流动性 5000 万、单票下限 2 万、候选池 50）逐一加拦截计数，输出每个调仓日的漏斗统计。
- **验收**：MA200 上方时段的零持仓日占比降至 <10%；日均持仓 ≥3 只。

### A-2 择时规则定稿（证据驱动，不与调研红线冲突）

- **调研定稿的红线**（不动）：指数位于 MA200 下方，持仓必须为 0%（S-2，生存门禁）。
- **实测发现的问题**（调研盲区）：裸破位即清仓在 2024 拉锯市被反复止损，回撤 43.08%→49.75%、换手 201%→243%。
- **修法**：执行层加确认与缓冲，判定层不动——
  - 连续 2 日收在 MA200 下方才清仓（过滤单日假破位）；
  - 偏离缓冲带 1%（贴着均线反复横跳不触发）；
  - 重新入场对称确认：站回 MA200 上方 2 日才重建仓位。
- **验收**：S-2 凭真实行为 PASS（违规 0 天，允许 T+1 成交滞后宽限）；MDD 回落到 43% 以下；换手回到 ~200%。

### A-3 G-MDD-1 回撤达标

- 目标 <35%。依赖 A-1 + A-2 合力；若仍超标，评估 MA200 上方的仓位梯度（上方时段允许降杠杆，下方时段仍是 0% 红线）。

## 4. Phase C：参数稳健性扫描（严格防过拟合）

- **网格**：股息率 {2%, 3%, 4%} × 调仓 {10, 20, 40} × 均线 {120, 200, 250} = 27 组。
- **算力预算**：本机 4 核，单次回测约 30 分钟、峰值内存约 1G；并行 3 路，全程约 3.5~4.5 小时。
- **纪律（继承调研的 DSR/试验计数思想）**：
  1. 全部试验进 registry（params_hash 已有机制），试验次数可追溯；
  2. 选参标准是**分年度稳健性**（各年超额中位数、最差年份下限），禁止按单点最优 CAGR 选参；
  3. 2023-2024 留作最终配置的伪样本外检验段；
  4. 接受任何『改进』前做多重检验修正（27 次试验下的显著性折扣）。

调研未覆盖、必须实测裁决的分叉（沿用 t312 诊断的决策规则）：

- 该决策点需输出评审记录，两种结果都合法，证据说话。

## 7. 纪律条款（全程有效）

1. **Fail-closed**：证据不足 ≠ 通过，缺数据一律 INCONCLUSIVE；
2. **出处三件套**：每次 run 必含 git SHA + data hash + timestamp；
3. **试验计数**：所有参数尝试留痕，接受改进前做多重检验修正；
4. **样本外意识**：2023-2024 为伪样本外段，调参阶段不得窥视；
5. **门禁不为过门禁而放宽**：判定层红线（S-2 破位 0% 持仓、MDD <35%、换手 <400%）不动；执行层细节（确认期、缓冲带、过滤器阈值）可迭代，每次迭代留产物对照；
6. **安全件不砍**：对账、留痕、kill switch。
