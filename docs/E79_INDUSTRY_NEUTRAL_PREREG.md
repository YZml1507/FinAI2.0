# E79 行业中性化选股臂预登记

> 预登记冻结：2026-09-23。**`--run` 前先定口径与判据**。

## 1. 假设

top40 等权篮的行业构成不受约束——分数头部集中期可能挤入单一赛道
（动量拥挤），放大回撤。行业上限约束迫使分散到次优行业的高分票，
先验方向：MDD↓，CAGR 代价未知（宽度稀释风险如实登记）。

## 2. 臂（域/窗口/成本/资金/权重模式全同基线 top40 等权）

行业源：data/industry/*.parquet（证监会分类 86 桶，updateDate ≤ 调仓日
最新快照——PIT）。选择规则：分数降序取，单行业名额 ≤ cap，
取不满时继续下探次优行业直至 target_count 或分数耗尽；
无行业记录代码单列伪桶（不受 cap）。

| 臂 | cap | 先验 |
|---|---|---|
| N-base | 无约束（对照=run 20260923-052313） | 基准 |
| N-cap6 | 6/40=15%/行业 | 温和分散，MDD↓ |
| N-cap3 | 3/40=7.5%/行业 | 强分散，MDD↓↓ 但 alpha 稀释风险高 |

判定口径：ΔCAGR 与 ΔMDD 对照基线。
- 判强：MDD ≤ 基线 −3pp 且 CAGR ≥ 基线 −3pp（净风险调整后占优）；
- 或 CAGR ≥ 基线 +3pp（分散反而增益）；
- 否则判弱/负，登记不追。

## 3. 门禁

同 gated 管线全门；判强才入晋级电池（分年/成本×3/OOS-2025 观察）。
