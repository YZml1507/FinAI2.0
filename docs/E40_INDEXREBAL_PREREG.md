# E40 指数定期调样事件族预登记（冻结版）

> 冻结时间：2026-09-21（先于任何筛选运行）。
> 数据：`data/index_rebal/`（csindex 公告附件解析，54 parquet；
> 300 调 463/调 463/备选 345，500 调 1100/1100/550，红利 160/160；
> 2023+ 红利源端无名单已登记）。
> 本族判完整体收单；事件研究沿用 e39/e30 同一管线与门禁。

## 一、假设与先验

指数定期调样：公告日（review_date，约生效前 2 周）→ 生效日
（effective_date，周五盘后）两时点。文献先验（A 股调样效应 +
国际 index-inclusion RD 证据）：被动资金建仓 + 主动抢跑使调入
名单在**公告→生效窗口**产生正向异常收益；生效后部分回落。调出
对称负向。备选名单（差一档调入的对照组）应弱于正式调入——
构成近似 RD 对照。

## 二、臂阵（6 臂，Bonferroni 修正 α 按 6 计）

| 臂 | 事件集 | 方向先验 |
|---|---|---|
| R1 | 调入沪深300（n≈463） | 正 |
| R2 | 调入中证500（n≈1100） | 正 |
| R3 | 调出 300+500 合并（n≈1563） | 负 |
| R4 | 调入中证红利（n≈160，小样本登记） | 正 |
| R5 | 备选名单 300+500（n≈895）——内建弱安慰剂 | ~0 或弱正 |
| R6 | 随机（日,股）安慰剂 3 重复核 | ~0 |

T0 = review_date（公告日），T+1 收盘入场（散户粒度口径）。
窗口：h ∈ {+1,+5,+10,+20} 交易日（事件族既有口径 HORIZONS）+
专项窗「T+1→生效日」（ann→eff 窗口是文献主效应段，
事后 drift 由 h 窗覆盖）。
基线 = 同日全 A 截面均值（e30 已证伪日中位复利基线，同纪律）。

## 三、判定门（与 e39 同构）

- 判「强」：任一窗 |t_cluster| ≥ 2.6 且方向与先验一致
  且年一致性（按事件年分组的同向占比）≥ 60%。
- 判「负」：全部窗 |t| < 2.6 或方向反先验。
- INCONCLUSIVE：n < 150 或簇功效不足。
- R5 若 |t|≥2.0 触发「名单泄露/边界混淆」存疑预案 →
  按 e39 纪律改随机安慰剂复核，不直接证伪基线。
- R5−(R1/R2) 差值作 RD 诊断量如实报告（不作判定臂）。

## 四、范围与红线

- 筛选窗：review_date ≤ 2024-12-31 的事件；2025+ 期次仅登记
  OOS 观察不入筛选（永久 OOS 纪律）。
- 不补算不存在的红利 2023+ 名单；缺口如实登记。
- 判「强」后走范畴评估：净边际、可成交性（调入股流动性通常
  充足）、与 5 持仓篮宽适配、是否仅尾部防撞 veto 化。
- 一切沿 e29/e30/e39 同套事件研究门禁，不降强度。

## 五、已知局限

- 300 调入股大盘属性使截面效应弱于 500——R2 先于 R1 的
