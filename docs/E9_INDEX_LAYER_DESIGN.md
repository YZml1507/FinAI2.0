# e9 设计稿：红利低波指数层（mid/ice 档持指数替代空仓）

> 创建：2026-09-17 ｜ 状态：设计稿，⛔ 未实施（等 R8 调研口径拆解后评审）
> 瓶颈声明（STRATEGY 五节）：针对「进攻层缺位（beta≈0）」+ G-2 判负暴露
> 的「阈值尖峰」双重瓶颈；预期改变 CAGR（收益端），同时用连续权重资产
> 弱化对硬阈值的依赖。机制复用 e7 demote 档位切换，不新开择时框架。

## 一、机制设计（一句话）

**attack 档持个股（现状），mid/ice 档从「空仓吃 GC001」改为「持红利低波
全收益指数资产」**；ice 深档可选继续 GC001（防御最底层）。

```
档位映射（建议版，待 R8 §四 分段数据复核）：
  attack → 红利池个股（现行逻辑不变）
  mid    → H20955 指数资产（吃权益 beta + 股息再投）
  ice    → GC001 计息（e6 机制不变，极端防御）
```

## 三、必须内置的诚实折减（fail-closed 原则延伸）

1. **指数全收益 ≠ ETF 实绩**：配置参数 `index_expense_drag`（年化拖累，
   赛前估 0.5-1.0%：管理费+跟踪误差+现金拖累），默认 fail-closed 不设
   默认乐观值——R8 报告给出标定后填入；
2. **2015-2019 段是「指数假设」**：该段无对应 ETF，回测注明口径；
3. **折溢价不进回测**：按指数价成交，实盘折价风险在 R8 §三 量化后
   进 G-3 复核，不进 NAV 模拟（一阶近似）。

## 四、扰动矩阵预案（G-2 不再犯同样的错）

e9 的关键差异：**没有新硬阈值**——指数资产权重由档位连续映射。
须扰动的参数仅剩 `index_expense_drag`（±50% 范围都应平滑）与既有
attack/defense（已知尖峰，不再重复测——登记为「构型固有风险，
指数层不新增敏感维」）。

## 五、预登记审计点（E7_PREREG 同款）

1. demote→index：跨界日 T+1 内全仓转入指数资产，0 违规；
2. index→attack：回场日卖出指数买个股，无重复下单；
3. 指数资产在册=持仓对账一致；分红再投已含在全收益价内，
   ⛔ 不许再叠加现金分红流水（双重计数）；
4. `cash_gc001`/`index_lowvol` 双模式互斥（e6 同款校验）。
