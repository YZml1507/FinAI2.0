# E48 监管函件事件族预登记（冻结版）

> 冻结时间：2026-09-21（先于数据落盘与任何筛选运行——
> 采集子会话在跑中，本稿基于已确认的字段口径冻结）。
> 数据源：cninfo hisAnnouncement 全量 + 交易所官方表（采集
> manifest 登记为准）；字段=ann_date/ts_code/letter_type(原文细类
> +归并大类)/title/url。方向=风控 veto 家族（e37 否决层同侧）。

## 一、先验

监管函件=负面信息事件（监管关注→问询→处罚链条）。文献与
业界证据：问询函公告后短期负漂；函件严重度分层（问询<关注<
警示函<立案调查）应有单调性。散户 T+1 可达（盘后公告）。
风险：函件披露日股价常已提前反应（盘中跳水后盘后公告），
T+1 口径可能只接住残段——如实评估。

## 二、臂阵（6 臂，Bonferroni）

| 臂 | 事件集 | 方向先验 |
|---|---|---|
| K1 | 问询函+年报问询函 | 负漂（弱档） |
| K2 | 关注函 | 负漂（中档） |
| K3 | 警示函+监管函+证监监管措施 | 负漂（强档） |
| K4 | 严重度单调性（K1<K2<K3 CAR 应递减） | 诊断臂 |
| K5 | 高频收函股：同股 30td 内 ≥2 封任类函件 | 负漂加强 |
| K6 | 随机（日,股）安慰剂门 | ~0 |

T0=公告日（announcementTime→交易日对齐：收盘后公告取当日，
盘中公告如实按披露日），T+1 收盘入场，h∈{1,5,10,20}，
基线=同日截面均值。同股同日多函合并为一事件（取最重类）。
筛选窗 ≤2024-12-31；2025+ 登记 OOS 观察。

## 三、判定门（同 e29/e43 骨架）

- 判「强」：|t_cluster|≥2.6 且 h20 方向合先验（负向）且
  年一致性 ≥60%（负向臂一致口径=负年占比）且 n≥300。
- 判定方向为负：判强者=风控剔除候选（收函后 N 日禁买窗），
  不与做多库混。
- K4 单调性报告不作判定。
- INCONCLUSIVE n<300。退市股覆盖（cninfo 保留退市记录）由
  manifest 抽查登记。

## 四、范围与红线

- 判强 veto 候选 → 范畴评估时须叠加现有 V1/V2/V3 集合并做
  重叠率诊断（函件股与户数激增/重复上榜重叠度）；
- 若判强但与已有 veto 事件重叠率>60% → 登记为增量价值低，
  不直接晋级。
- 盘中/盘后披露时间不可得（cninfo 只有日期戳）——T0 口径
  记为披露日，效应若已被当日 price-in 则判负如实，不构
  成「效应不存在」证据。

## 五、已知局限

- 函件类型归并口径=采集脚本 mapping（细类保留原文可复核）。
- 交易所官方表与 cninfo 检索可能交叉重复 → 同股同函按
  announcementId/标题去重，残余重复按同股同日合并吸收。
- 监管函密度随监管周期波动（2018 后严监管时代量升）——
  年一致性门如实暴露 regime 结构。
