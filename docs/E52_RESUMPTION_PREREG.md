# E52 停牌复牌事件族预登记（冻结版）

> 冻结时间：2026-09-21（先于任何筛选运行）。
> 数据源：面板内停牌检测（panel_close NaN 连续段≥L 后首个非 NaN
> 交易日=复牌日 T0；上市前 NaN 段不算停牌）。零新数据依赖。
> 文献先验：A 股长期停牌多藏利空兑现（重组失败/风险处置），
> 复牌后负漂移；2015 股灾期集体停牌为极端样本，如实登记。

## 一、臂阵（5 臂，Bonferroni）

| 臂 | 事件集 | 方向先验 |
|---|---|---|
| R1 | 停牌 ≥60td 后复牌 | 负（长停藏利空） |
| R2 | 停牌 20–59td 复牌 | 负（较弱） |
| R3 | 停牌 5–19td 复牌 | ~0（常规核查性停牌对照） |
| R4 | 复牌首日跌幅 ≥5% 事件（在全体复牌中再筛） | 负加强（下杀延续） |
| R5 | 随机安慰剂门 | ~0 |

T0=复牌日，T+1 收盘入场，h∈{1,5,10,20}，基线=同日截面均值。
同股复牌事件间隔 ≥20td 去重；筛选窗 ≤2024-12-31。

## 二、判定门（同构骨架）

- 判「强」：|t_cluster|≥2.6 + 方向合先验 + 年一致性≥60% + n≥300。
- **池内命中率前置门（e50 元教训）**：判强负臂先算事件×487 池
  命中率；<8% 直接登记「宽域待载体」，免跑引擎 A/B。
- 负臂判强 → veto 候选（候选库登记，载体问题见 memo 46）。
- 停牌段定义偏差如实披露：NaN 段含数据缺口可能性，
  用 L≥20td 阈值压制（日常数据洞通常 <5td）。

## 三、范围

- 判强且落池率达标 → veto 增量按 e50 电池流程复测；
- 正臂若判强（如复牌补涨）→ 事件做多评估含可成交性切片。

## 四、已知局限

- 停牌原因不可得（重组/核查/风险警示混在一起），效应异质
  如实披露；R4 用首日跌幅作替代分层；
- 2015 年股灾期停牌潮事件高度簇聚——簇稳健 t 已按 T0 聚合，
  年一致性指标会显形该集中。

## 五、收单（2026-09-21 当日冻结当日收单）

**裁决**：
- R2 落池率 8.4% 刚过前置门 → 候选库 veto 侧登记，但标注
  「贴线，池内边际预期≈0」（参照 e50：8% 落池→零增量）；
- R1/R4 登记「宽域待载体」（e51 队列条件件）——R4 为项目史上
  最强单事件负信号（−12.6%/20d, t−15.3），其标的几乎全部
  在红利池外；
- 价值不在 veto 引擎增量（池内近零），在**全 A 风险排除清单**
  与 e51 宽域载体的候选弹药。

**机制注记**：停牌期日日收益不可定义（R4 一度 n=0），改用
复牌跳空 gap=T0收/停前末收−1 分层——停期含除权事件污染
为已知噪声。
